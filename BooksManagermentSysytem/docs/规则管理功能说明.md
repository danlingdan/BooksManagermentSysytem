# 借阅规则与处罚规则管理功能说明

## 功能概述

本功能允许管理员为不同读者类型（本校学生/本校教师/校外人员）配置灵活的借阅规则和处罚规则，实现差异化的图书馆服务管理。

---

## 一、借阅规则管理

### 1.1 功能简介
为不同读者类型配置借阅参数，包括最大借阅数量、借阅期限、续借规则、可借图书类型等。

### 1.2 可配置参数

| 参数 | 说明 | 范围 | 默认值（学生） |
|------|------|------|--------------|
| 最大借阅数量 | 一次最多可借阅的图书数量 | 1-10本 | 3本 |
| 最大分类数 | 一次最多可借阅的图书分类数 | 1-5个 | 2个 |
| 借阅天数 | 标准借阅期限 | 1-90天 | 7天 |
| 最大续借次数 | 可续借的最大次数 | 0-5次 | 2次 |
| 续借天数 | 每次续借的天数 | 1-30天 | 7天 |
| 允许借工具书 | 是否可借阅工具书区图书 | 是/否 | 否 |
| 允许借新书 | 是否可借阅新书区图书 | 是/否 | 是 |
| 允许借热门书 | 是否可借阅热门区图书 | 是/否 | 是 |

### 1.3 默认规则配置

#### 本校教师（最优惠）
- 最大借阅数：**5本**
- 最大分类数：**3个**
- 借阅天数：**14天**
- 最大续借次数：**3次**
- 续借天数：**14天**
- 工具书：**允许**
- 新书/热门书：允许

#### 本校学生（标准）
- 最大借阅数：**3本**
- 最大分类数：**2个**
- 借阅天数：**7天**
- 最大续借次数：**2次**
- 续借天数：**7天**
- 工具书：**不允许**
- 新书/热门书：允许

#### 校外人员（最严格）
- 最大借阅数：**2本**
- 最大分类数：**2个**

### 1.4 操作说明

1. **查看规则**

2. **修改规则**
   - 选择要修改的读者类型

   - 点击"保存"

3. **规则验证**
   - 系统自动验证参数范围
   - 保存前显示确认对话框

## 二、处罚规则管理

### 2.1 功能简介
为不同读者类型配置罚款标准，包括逾期罚款、损坏赔偿、丢失赔偿等计算规则。

### 2.2 可配置参数

| 参数 | 说明 | 范围 | 默认值（学生） |
|------|------|------|--------------|
| 逾期书价% | 逾期罚款的书价比例 | 0-100% | 10% |
| 每天罚款 | 逾期每天的固定罚款 | 0-10元 | 0.10元 |
| 丢失赔偿% | 丢失图书的赔偿比例 | 50-300% | 100% |
| 严重破损% | 严重破损的赔偿比例 | 10-100% | 50% |
| 轻微破损% | 轻微破损的赔偿比例 | 0-50% | 25% |
| 最大逾期罚款 | 逾期罚款的上限 | 0-1000元 | 50元 |
| 宽限天数 | 免罚款的宽限期 | 0-7天 | 1天 |

### 2.3 罚款计算公式

#### 逾期罚款
```
罚款 = 书价 × 逾期书价% + (逾期天数 - 宽限天数) × 每天罚款

注：宽限期内不收取罚款
    罚款不超过"最大逾期罚款"设置
```

**示例（书价¥50，逾期5天，宽限1天）：**
```
罚款 = 50 × 10% + (5 - 1) × 0.10
     = 5 + 0.40
     = ¥5.40
```

#### 轻微破损
```
罚款 = 书价 × 轻微破损% + 逾期罚款（如有）
```

#### 严重破损
```
罚款 = 书价 × 严重破损% + 逾期罚款（如有）
```

#### 图书丢失
```
罚款 = 书价 × 丢失赔偿%
```

#### 本校教师（最优惠）

- 轻微破损%：**20%**
- 最大逾期罚款：**¥100**（上限更高）
- 宽限天数：**3天**（更长宽限期）

#### 本校学生（标准）
- 逾期书价%：**10%**
- 每天罚款：**¥0.10**
- 丢失赔偿%：**100%**
- 严重破损%：**50%**
- 轻微破损%：**25%**
- 最大逾期罚款：**¥50**
- 宽限天数：**1天**

#### 校外人员（最严格）
- 逾期书价%：**15%**（更高）
- 每天罚款：**¥0.15**
- 丢失赔偿%：**150%**（含管理成本）
- 严重破损%：**70%**
- 轻微破损%：**30%**

## 六、注意事项

### 6.1 规则修改影响
- ⚠️ 规则修改**立即生效**
- ⚠️ 已借阅图书**不受新规则影响**
- ⚠️ 新借阅操作使用**最新规则**

### 6.2 安全建议
- ✅ 仅管理员可修改规则
- ✅ 修改前备份数据库
- ✅ 重大调整前通知读者

### 6.3 合理性检查
- ✅ 教师规则应优于学生
- ✅ 学生规则应优于校外人员
- ✅ 罚款不宜过高或过低

## 八、常见问题

### Q1: 修改规则后是否影响已借图书？
**A:** 不影响。已借图书的归还期限和罚款按借阅时的规则计算。

### Q2: 可以为个别读者设置特殊规则吗？
**A:** 当前版本按读者类型设置规则。如需个别处理，建议由管理员手动调整。

### Q3: 罚款上限的作用是什么？
**A:** 防止逾期时间过长导致罚款过高。达到上限后不再增加。

### Q4: 宽限期如何计算？
**A:** 宽限期内不计算罚款。例如宽限1天，逾期2天则只罚1天。

### Q5: 如何临时停用某个规则？
**A:** 将`is_active`字段设为0，或将参数设为极端值（如借阅天数设为1天）。
