# 图书借阅与归还功能说明

## 一、借阅功能（BorrowBookControl）

### 1.1 功能概述
支持扫描借书证和图书条码发起借阅，自动校验借阅资格（借阅数量限制、读者状态、图书状态、未付罚款等），自动计算应还日期，创建借阅记录，更新图书和库存状态。

### 1.2 借阅规则
- **最大借阅数量**：每次最多借阅 3 本书
- **分类限制**：每次最多借阅 2 个分类的书籍
- **借阅期限**：7 天
- **工具书限制**：工具书区（REFERENCE）和仅供查阅（TOOL_ONLY）书籍不可外借

### 1.3 借阅资格校验

#### 借书证校验
- ✅ 借书证状态必须为"正常"
- ✅ 借书证必须在有效期内
- ❌ 注销、挂失、补办中的借书证不能借阅

#### 罚款校验
- ❌ 有未支付罚款的读者不能借阅
- ℹ️ 显示未支付罚款总金额

#### 逾期校验
- ❌ 有逾期未还书籍的读者不能借阅
- ℹ️ 显示逾期书籍数量

#### 借阅数量校验
- ✅ 当前借阅数 + 本次借阅数 ≤ 3 本
- ℹ️ 显示当前已借数量和可借数量

#### 图书状态校验
- ✅ 图书状态必须为 AVAILABLE（可借阅）
- ❌ BORROWED（已借出）、RESERVED（已预约）、OFF_SHELF（已下架）的图书不可借阅

#### 分类限制校验
- ✅ 本次借阅涉及的分类数 ≤ 2 个
- ℹ️ 显示已选分类列表

### 1.4 操作流程

```
1. 输入/扫描借书证号 → 点击"查询"
   ↓
2. 系统校验读者资格
   ├─ 通过 → 显示读者信息（姓名、类型、单位、已借数量、可借数量）
   └─ 不通过 → 显示错误原因（状态异常、有罚款、有逾期等）
   ↓
3. 输入/扫描图书馆藏条码 → 点击"添加"
   ↓
4. 系统校验图书
   ├─ 通过 → 添加到待借列表
   └─ 不通过 → 显示错误原因（状态异常、工具书、分类超限等）
   ↓
5. 重复步骤3，添加多本书（最多3本）
   ↓
6. 点击"确认借阅"
   ↓
7. 系统显示确认对话框
   ├─ 书籍列表
   ├─ 借期：7天
   ├─ 应还日期
   └─ 逾期罚款规则
   ↓
8. 确认 → 创建借阅记录
   ├─ 插入 borrow_record（借阅单头）
   ├─ 插入 bookborrow（借阅明细）
   └─ 更新 BOOK_ITEM.current_status = BORROWED
   ↓
9. 显示成功消息并清空
```

### 1.5 数据库操作

```sql
-- 创建借阅记录（单头）
INSERT INTO borrow_record (cardID, borrowdate, bcomplete)
VALUES (@cardID, GETDATE(), N'完好');

-- 创建借阅明细
INSERT INTO bookborrow (borrow_record_id, cardID, bookID, borrowdate)
VALUES (@recordId, @cardID, @bookID, GETDATE());

-- 更新图书状态
UPDATE BOOK_ITEM 
SET current_status = N'BORROWED', 
    status_changed_date = GETDATE()
WHERE item_barcode = @barcode;
```

## 二、归还功能（ReturnBookControl）

### 2.1 功能概述
支持扫描条码归还图书，进行图书完整性检查，自动计算逾期天数，逾期或损坏时自动生成罚款，更新图书状态（在架/待修复/丢失），更新借阅记录。

### 2.2 归还状态选项
1. **完好** - 正常归还，无损坏
2. **轻微破损** - 轻微损坏，罚款为严重破损的 50%
3. **严重破损** - 严重损坏，需赔偿 50% 书价
4. **丢失** - 图书丢失，需赔偿 100% 书价

### 2.3 罚款计算规则

#### 逾期罚款
```
罚款金额 = 书价 × 10% + 逾期天数 × ¥0.10
```

**示例**：
- 书价：¥50.00
- 逾期：5 天
- 罚款 = 50 × 0.1 + 5 × 0.1 = ¥5.50

#### 轻微破损
```
罚款金额 = 书价 × 25% + 逾期罚款（如有）
```

#### 严重破损
```
罚款金额 = 书价 × 50% + 逾期罚款（如有）
```

#### 丢失赔偿
```
罚款金额 = 书价 × 100%
```

### 2.4 图书状态更新规则

| 归还状态 | current_status | physical_condition | 说明 |
|---------|----------------|-------------------|------|
| 完好 | AVAILABLE | GOOD | 正常流通 |
| 轻微破损 | AVAILABLE | GOOD | 可继续流通 |
| 严重破损 | AVAILABLE | DAMAGED | 标记为损坏 |
| 丢失 | OFF_SHELF | DAMAGED | 下架处理 |

### 2.5 操作流程

```
1. 输入/扫描借书证号 → 点击"查询"
   ↓
2. 系统查询已借书籍列表
   ├─ 显示：馆藏码、书名、ISBN、分类、借阅日期、应还日期、状态、逾期天数、单价
   ├─ 颜色标识：
   │  ├─ 逾期：红色背景
   │  └─ 即将到期（≤2天）：黄色背景
   └─ 提示：读者姓名、借书证状态、待归还数量、逾期数量
   ↓
3. 选择要归还的书籍
   ↓
4. 选择归还状态（完好/轻微破损/严重破损/丢失）
   ↓
5. 系统自动计算并显示预计罚款
   ├─ 罚款金额
   └─ 罚款明细（逾期天数、损坏类型等）
   ↓
6. （可选）填写备注说明
   ↓
7. 点击"确认归还"
   ↓
8. 系统显示确认对话框
   ├─ 馆藏码、书名
   ├─ 借阅日期、归还状态
   ├─ 备注说明
   └─ 罚款信息（如有）
   ↓
9. 确认 → 执行归还操作
   ├─ 更新 bookborrow.overdate = GETDATE()
   ├─ 更新 bookborrow.add_note（记录逾期天数和备注）
   ├─ 更新 borrow_record（如果该批次全部归还）
   ├─ 更新 BOOK_ITEM 状态和物理状态
   └─ 创建罚款记录（如有）
   ↓
10. 显示成功消息并刷新列表
```

### 2.6 数据库操作

```sql
-- 更新借阅明细
UPDATE bookborrow 
SET overdate = GETDATE(), 
    add_note = @note 
WHERE bookborrow_id = @id;

-- 更新借阅记录（如果该批次全部归还）
UPDATE borrow_record
SET overdate = GETDATE(),
    bcomplete = @condition,
    add_note = @note
WHERE borrow_record_id = @recordId
  AND NOT EXISTS (
      SELECT 1 FROM bookborrow 
      WHERE borrow_record_id = @recordId 
        AND overdate IS NULL
  );

-- 更新图书状态
UPDATE BOOK_ITEM 
SET current_status = @status, 
    physical_condition = @condition,
    status_changed_date = GETDATE()
WHERE item_barcode = @barcode;

-- 创建罚款记录（如有）
INSERT INTO fine (cardID, readername, reason, amount, fine_status, created_time)
VALUES (@cardID, @name, @reason, @amount, N'未支付', GETDATE());
```

## 四、罚款计算器（FineCalculator）

### 4.1 逾期罚款
```csharp
decimal CalculateOverdueFine(decimal bookPrice, int overdueDays)
{
    return bookPrice * 0.1m + overdueDays * 0.1m;
}
```

### 4.2 丢失赔偿
```csharp
decimal CalculateLostFine(decimal bookPrice)

    return bookPrice * 1.0m;
```

```csharp
decimal CalculateDamagedFine(decimal bookPrice)
```

## 七、注意事项

### 7.1 数据一致性
- 借阅时必须同时更新 borrow_record、bookborrow、BOOK_ITEM 三张表
- 归还时必须同时更新 bookborrow、borrow_record（可选）、BOOK_ITEM、fine（如有）
- 使用事务确保数据一致性

### 7.2 并发控制
- bookborrow 表有过滤唯一索引：`overdate IS NULL` 时同一本书只能有一条借阅记录
- 防止同一本书被重复借出

### 7.3 性能优化
- 借阅校验时一次性查询所有需要的信息
- 避免多次数据库往返

### 7.4 用户体验
- 读者登录时自动填充借书证号
- 支持条码扫描（键盘输入+回车）
- 实时显示罚款预览
- 颜色标识（逾期、即将到期）
- 友好的错误提示
