# 用户管理和系统日志功能实现说明

## 功能概述

为图书管理系统实现了两个系统管理功能模块：
1. **用户管理**（UserManagementControl）
2. **系统日志**（SystemLogControl）

## 一、用户管理功能（UserManagementControl.cs）

### 功能特性

#### 1. 用户列表管理
显示系统所有用户账户，包括：
- 用户名
- 显示名称
- 角色（读者/图书管理员/图书采编员/系统管理员）
- 借书证号（读者）
- 账户状态（启用/禁用）
- 最后登录时间

#### 2. 用户搜索与筛选
- 按用户名或显示名称搜索
- 按角色筛选（全部角色/读者/图书管理员/图书采编员/系统管理员）

#### 3. 新建用户
**必填字段：**
- 用户名（唯一，不可重复）
- 显示名称
- 密码（至少6位）
- 用户角色

**可选字段：**
- 借书证号（读者角色必填，需绑定有效借书证）
- Windows账户（用于Windows集成认证）

**特性：**
- 密码使用SHA256加密存储
- 每个用户使用唯一的盐值（Salt）
- 读者角色必须绑定有效的借书证
- 借书证选择器自动过滤已绑定和无效的借书证

#### 4. 编辑用户
- 修改显示名称
- 更改用户角色
- 绑定/更改借书证
- 绑定/更改Windows账户
- 启用/禁用账户
- 修改密码（留空表示不修改）

#### 5. 重置密码
- 管理员可将任何用户密码重置为默认密码：`123456`
- 操作需二次确认

#### 6. 删除用户
- 不能删除当前登录用户
- 删除操作不可恢复，需二次确认

#### 7. 安全特性
- 密码使用SHA256 + Salt加密存储
- 用户名唯一性校验
- 借书证绑定校验（防止重复绑定）
- 角色权限管理（与AuthenticationService集成）

### 数据库表结构
```sql
CREATE TABLE [system_user](
    user_id INT IDENTITY(1,1) PRIMARY KEY,
    username NVARCHAR(50) NOT NULL UNIQUE,
    password_hash NVARCHAR(256) NOT NULL,
    salt NVARCHAR(64) NOT NULL,
    user_role NVARCHAR(20) NOT NULL,  -- Reader/Librarian/Cataloger/Admin
    cardID NVARCHAR(20) NULL,          -- FK to reader(cardID)
    windows_account NVARCHAR(100) NULL,
    display_name NVARCHAR(50) NOT NULL,
    is_active BIT NOT NULL DEFAULT(1),
    created_time DATETIME2(0) NOT NULL DEFAULT(SYSDATETIME()),
    last_login_time DATETIME2(0) NULL
);
```

## 二、系统日志功能（SystemLogControl.cs）

### 功能特性

#### 1. 日志查询
显示catalog_log表中的所有操作记录：
- 对象类型（书目/馆藏实体/图书分类/库位）
- 对象标识（ISBN/馆藏码/分类号/库位编码）
- 操作类型（新增/删除/更新/分类/上架/下架/状态变更）
- 操作员（执行操作的用户名）
- 操作时间
- 备注说明

#### 2. 高级筛选
支持多条件组合筛选：
- **日期范围**：起始日期 至 结束日期（默认最近7天）
- **对象类型**：全部对象/书目/馆藏实体/图书分类/库位
- **操作类型**：全部操作/新增/删除/更新/分类/上架/下架/状态变更
- **操作员**：按操作员名称模糊搜索

#### 3. 视觉高亮
- 删除操作：红色加粗字体
- 新增操作：绿色字体
- 更新操作：蓝色字体
- 其他操作：默认字体

#### 4. 数据导出
- 支持导出为CSV或TXT文件
- 自动处理特殊字符（逗号、引号、换行符）
- 文件名包含时间戳：`系统日志_20250120153045.csv`

#### 5. 统计信息
- 显示当前筛选条件下的总记录数
- 提示日志保留期限（180天）

### 数据库表结构
```sql
CREATE TABLE catalog_log(
    log_id BIGINT IDENTITY(1,1) PRIMARY KEY,
    target_type NVARCHAR(30) NOT NULL,   -- BIBLIOGRAPHY/BOOK_ITEM/CATEGORY/LOCATION
    target_id NVARCHAR(50) NOT NULL,
    action_type NVARCHAR(30) NOT NULL,   -- 新增/删除/更新/分类/上架/下架/状态变更
    operator NVARCHAR(50) NOT NULL,
    action_time DATETIME2(0) NOT NULL DEFAULT(SYSDATETIME()),
    note NVARCHAR(500) NULL
);
```

### 日志记录规范

#### 对象类型枚举
- `BIBLIOGRAPHY` - 书目管理操作
- `BOOK_ITEM` - 馆藏实体操作
- `CATEGORY` - 图书分类操作
- `LOCATION` - 库位管理操作

#### 操作类型枚举
- `新增` - 创建新记录
- `删除` - 删除记录
- `更新` - 修改记录
- `分类` - 分类调整
- `上架` - 图书上架
- `下架` - 图书下架
- `状态变更` - 状态修改

#### 日志记录示例
```sql

    N'9787115216878',

```

## 四、技术特点

### 1. 安全性
- **密码加密**：SHA256 + 随机盐值
- **权限隔离**：基于角色的访问控制
- **操作审计**：所有管理操作记录日志
- **防删除保护**：不能删除当前登录用户

### 2. 用户体验
- **智能筛选**：多条件组合查询
- **视觉反馈**：颜色区分不同操作类型
- **友好提示**：操作前二次确认
- **便捷导出**：一键导出日志数据

### 3. 数据完整性
- **唯一性约束**：用户名不可重复
- **外键约束**：借书证必须存在
- **状态校验**：借书证必须正常且未过期
- **绑定校验**：一个借书证只能绑定一个用户

### 4. 代码质量
- **WinForms最佳实践**：遵循Designer代码规范
- **异常处理**：完整的try-catch机制
- **资源管理**：使用using正确释放资源
- **命名规范**：清晰的控件命名

## 五、使用场景

### 用户管理场景

#### 场景1：新员工入职
1. 管理员登录系统
2. 进入"系统管理" → "用户管理"
3. 点击"新建用户"
4. 填写用户信息，选择角色（如：图书管理员）
5. 如果是读者角色，绑定借书证
6. 点击"保存"

#### 场景2：员工离职
1. 搜索该员工账户
2. 取消勾选"启用"
3. 点击"保存"（禁用账户，保留历史记录）

#### 场景3：忘记密码
1. 搜索用户
2. 点击"重置密码"
3. 告知用户新密码：`123456`
4. 用户登录后自行修改密码

### 系统日志场景

#### 场景1：审计检查
1. 选择日期范围（如：本月）
2. 选择对象类型（如：书目）
3. 查看所有书目管理操作
4. 导出CSV用于归档

#### 场景2：问题追踪
1. 输入操作员名称
2. 查看该操作员的所有操作
3. 定位问题操作
4. 导出证据

#### 场景3：统计分析
1. 选择"新增"操作类型
2. 统计某时间段新增的资源数量
3. 导出数据进行分析

## 六、注意事项

### 用户管理
1. **默认管理员**：系统初始化时应创建默认admin账户
2. **密码策略**：建议定期提醒用户修改密码
3. **角色变更**：修改用户角色时需谨慎，确保不影响业务
4. **借书证绑定**：读者账户必须绑定有效借书证才能借阅

### 系统日志
1. **日志清理**：建议定期归档并清理180天前的日志
2. **性能优化**：大量日志查询时建议添加索引
3. **导出限制**：大批量导出时注意文件大小
4. **隐私保护**：日志导出应遵守数据保护规定
