# 📚 借阅归还功能 - README

## 🎯 功能概述

本次更新完善了图书管理系统的核心功能：**借阅**和**归还**。

---

## ✨ 主要特性

### 借阅功能
- ✅ 完整的借阅资格校验（借书证状态、罚款、逾期）
- ✅ 自动计算应还日期（借期7天）
- ✅ 支持扫描条码快速借阅
- ✅ 实时显示可借数量
- ✅ 友好的错误提示

### 归还功能
- ✅ 自动计算逾期天数和罚款
- ✅ 支持多种归还状态（完好/轻微破损/严重破损/丢失）
- ✅ 实时罚款预览
- ✅ 颜色标识（逾期、即将到期）
- ✅ 自动更新图书状态

---

## 📖 快速开始

### 借阅图书
1. 打开 **读者服务 → 借阅图书**
2. 输入借书证号，点击"查询"
3. 扫描图书条码，点击"添加"（最多3本）
4. 点击"确认借阅"

### 归还图书
1. 打开 **读者服务 → 归还图书**
2. 输入借书证号，点击"查询"
3. 选择要归还的书籍
4. 选择归还状态（完好/破损/丢失）
5. 查看罚款预览
6. 点击"确认归还"

---

## 💰 罚款规则

### 逾期罚款
```
罚款 = 书价 × 10% + 逾期天数 × ¥0.10
```

### 损坏赔偿
- **轻微破损**：书价 × 25%
- **严重破损**：书价 × 50%
- **丢失**：书价 × 100%

### 示例
| 书价 | 状态 | 逾期 | 罚款 |
|------|------|------|------|
| ¥50 | 完好 | 0天 | ¥0.00 |
| ¥50 | 完好 | 5天 | ¥5.50 |
| ¥50 | 轻微破损 | 0天 | ¥12.50 |
| ¥50 | 严重破损 | 5天 | ¥30.50 |
| ¥50 | 丢失 | - | ¥50.00 |

## 📋 借阅规则

- 最多借 **3本书**
- 最多 **2个分类**
- 借期 **7天**
- 工具书**不可外借**
