```csharp

bool valid = BorrowRules.ValidateBorrowRequest(
    reader.ReaderType,  // "本校学生"
    currentBorrowed, 
    selectedBooks, 
    out errorMsg
);

// 罚款计算（自动应用宽限期和上限）
decimal fine = FineCalculator.CalculateOverdueFine(
    bookPrice, 
    overdueDays, 
    reader.ReaderType  // "本校教师" - 享受3天宽限期
);

// 计算到期日期（根据读者类型）
DateTime dueDate = BorrowRules.CalculateDueDate(
    borrowDate, 
    reader.ReaderType  // 教师14天，学生7天，校外5天
);
```

## 💡 核心特性

### ✅ 差异化管理

| 读者类型 | 最大借阅数 | 借期 | 续借 | 宽限期 | 逾期罚款示例(¥50/5天) |
|---------|-----------|------|------|--------|---------------------|
| 本校教师 | 5本 | 14天 | 3次×14天 | 3天 | ¥5.16 |
| 本校学生 | 3本 | 7天 | 2次×7天 | 1天 | ¥5.40 |
| 校外人员 | 2本 | 5天 | 1次×5天 | 0天 | ¥8.25 |

### ✅ 实时生效
- 规则修改后**立即应用**
- 10分钟智能缓存
- 保存时自动清除缓存

### ✅ 完全可配置
- **9个借阅参数**：最大借阅数、分类数、借期、续借等
- **9个处罚参数**：逾期比例、罚款上限、宽限期等
- **界面化操作**：无需修改代码

### ✅ 向后兼容

## 🎯 使用场景

### 场景1：学期开始调整
```
问题：新学期借期需要延长
解决：管理员修改"借阅天数"从7天改为14天
结果：立即生效，新借阅使用14天借期
```

### 场景2：教师科研优惠
```
问题：教师科研需要更多书籍
解决：修改"本校教师"规则，最大借阅数从3本改为5本
结果：教师可借5本，学生仍为3本
```

### 场景3：罚款政策调整
```
问题：学生反馈罚款过高
解决：调整"本校学生"逾期罚款比例从15%降至10%，增加1天宽限期
结果：罚款减少，学生体验改善
```

### 场景4：校外人员限制
```
问题：校外人员占用过多资源
解决：限制校外人员借期为5天，不允许借新书和热门书
结果：资源优先服务校内师生
```

## 🐛 故障排除

### 问题1：规则修改不生效
**原因**：缓存未清除  
**解决**：
```csharp
// 手动清除缓存
BorrowRules.ClearCache();
FineCalculator.ClearCache();
```

### 问题2：菜单项不显示
**原因**：非管理员用户  
**解决**：使用管理员账户登录

### 问题3：数据库连接失败
**原因**：规则表未创建  
**解决**：执行 `create_rules_tables.sql` 和 `init_rules_data.sql`

### 问题4：使用默认规则而非数据库规则
**原因**：数据库查询失败或规则不存在  
**解决**：检查存储过程和规则数据是否正确
