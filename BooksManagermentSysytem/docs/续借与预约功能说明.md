本文档介绍图书管理系统中的**图书续借**和**图书预约管理**功能的实现细节和使用说明。

## 一、图书续借功能 (4.3)

### 1.1 功能简介

读者可申请续借图书，系统自动校验续借资格（续借次数限制、是否有人预约、是否逾期等），通过后自动延长应还日期，记录续借次数和时间。

### 1.2 业务规则

| 规则项 | 说明 |
|--------|------|
| 续借次数限制 | 根据读者类型不同，最大续借次数不同（本校学生2次，本校教师3次，校外人员1次） |
| 续借期限 | 根据读者类型不同，每次续借延长天数不同（本校学生7天，本校教师30天，校外人员7天） |
| 续借条件 | 未逾期、无人预约、借书证正常、无未支付罚款 |
| 续借记录 | 记录续借次数和最后续借时间 |
| 到期日计算 | 从当前日期开始，延长相应的续借天数 |

### 1.4 使用流程

1. **读者查询**：输入借书证号，加载读者信息和可续借书籍列表
2. **选择书籍**：从列表中选择要续借的书籍，查看续借信息
3. **办理续借**：点击"办理续借"按钮，系统自动校验并执行续借
4. **查看结果**：显示续借成功信息和新的到期日期

### 1.5 校验逻辑

系统会依次校验以下条件：

1. ✅ 借阅记录是否存在且未归还
2. ✅ 是否已逾期（逾期不能续借）
3. ✅ 续借次数是否达到上限
4. ✅ 是否有其他读者预约此书
5. ✅ 读者是否有未支付罚款

任一条件不满足，续借请求将被拒绝，并显示具体原因。

## 二、图书预约管理功能 (4.4)

### 2.1 功能简介

读者可预约已借出或新书，系统校验预约资格，管理预约排队顺序，图书归还后通知预约者，支持预约取书、预约取消、预约过期自动取消等流程。

### 2.2 业务规则

| 规则项 | 说明 |
|--------|------|
| 预约类型 | BORROW_RESERVE（借阅预约）、NEW_BOOK（新书预约） |
| 预约数量限制 | 最多同时预约3本书 |
| 分类限制 | 最多预约2个分类的书籍 |
| 预约有效期 | 3天（从预约时间开始计算） |
| 预约状态 | PENDING（待处理）、FULFILLED（已完成）、EXPIRED（已过期）、CANCELLED（已取消） |
| 预约条件 | 借书证正常、无未支付罚款、无其他待处理预约 |
| 预约优先级 | 按预约时间先后排序 |
| 自动过期 | 系统自动检查并处理过期预约 |

### 2.4 使用流程

#### 2.4.1 创建预约流程

1. **读者查询**：输入借书证号，系统校验借书证状态和是否有待处理预约
2. **搜索图书**：输入关键词搜索要预约的图书
3. **添加预约**：从搜索结果中选择图书添加到预约列表
4. **确认预约**：检查预约列表，点击"确认预约"
5. **查看结果**：显示预约成功信息和取书截止时间

#### 2.4.2 取消预约流程

1. **查看预约**：切换到"我的预约"标签页
2. **选择预约**：选择要取消的预约（只能取消"待处理"状态的预约）
3. **确认取消**：点击"取消预约"按钮并确认
4. **查看结果**：预约状态更新为"已取消"，图书状态恢复

#### 2.4.3 预约过期处理

系统会自动处理过期预约：

- 定时检查：调用 `sp_ExpireReservations` 存储过程
- 手动触发：点击"刷新"按钮时检查过期预约
- 处理逻辑：
  1. 将状态更新为 EXPIRED
  2. 如果是借阅预约，恢复图书状态为 BORROWED
  3. 记录取消原因："系统自动取消：预约已过期"

### 2.5 校验逻辑

创建预约时，系统会依次校验：

1. ✅ 借书证状态是否正常且未过期
2. ✅ 是否有未支付罚款
3. ✅ 是否已预约过该书籍
4. ✅ 当前待处理预约数量是否超限
5. ✅ 图书状态是否符合预约类型要求
6. ✅ 工具书区/仅供查阅书籍不可预约

### 2.6 预约与归还的集成

当图书归还时，系统会检查是否有预约：

## 五、常见问题

### Q1: 续借后的到期日如何计算？

**A:** 从当前日期（续借日期）开始，加上该读者类型的续借天数。例如：
- 本校学生续借：当前日期 + 15天
- 本校教师续借：当前日期 + 30天
- 校外人员续借：当前日期 + 7天

### Q2: 预约过期后会自动取消吗？

**A:** 是的。系统有两种机制处理过期预约：
1. 定时任务：可配置定时调用 `sp_ExpireReservations` 存储过程
2. 手动触发：用户点击"刷新"时检查并处理过期预约

### Q3: 如何修改预约有效期？

**A:** 修改 `BusinessRules.cs` 中的常量 `ReservationDays`：
```csharp
public const int ReservationDays = 3; // 修改为所需天数
```

### Q4: 如何修改不同读者类型的续借规则？

**A:** 直接修改数据库中的 `borrow_rule` 表数据，或通过借阅规则管理界面（`BorrowRuleManagementControl`）进行配置。

### Q5: 预约和续借可以同时进行吗？

**A:** 不可以。如果一本书已被预约，则不能续借；如果读者有待处理预约，则不能创建新预约。
