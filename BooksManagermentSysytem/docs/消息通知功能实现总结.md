## 🎯 核心功能

### 消息类型支持
1. **系统消息** - 一般系统通知
2. **逾期提醒** - 图书已逾期提醒（高优先级）
3. **即将到期提醒** - 提前3天提醒（普通优先级）
4. **预约到书通知** - 预约图书已可取
5. **预约过期通知** - 预约已过期
6. **罚款通知** - 罚款待支付（高优先级）
7. **借书证到期提醒** - 提前30天提醒
8. **系统公告** - 管理员群发公告

### 自动提醒规则
```
即将到期：提前 3 天开始提醒
已逾期：每天检测并发送提醒（避免重复）
借书证到期：提前 30 天提醒
罚款预估：实时计算罚款金额
```

### 罚款计算
```
逾期罚款 = 书价 × 10% + 逾期天数 × ¥0.10
```

## 💻 技术实现

### 设计模式
- **单例模式**：`NotificationService`
- **模板方法模式**：消息模板支持
- **缓存机制**：避免重复发送提醒

### 关键特性
- **防重复发送**：同一天同一条提醒只发送一次
- **智能模板**：支持参数化消息模板
- **优先级管理**：低/普通/高/紧急四个级别
- **批量操作**：标记全部已读、批量删除
- **颜色标识**：未读消息、紧急消息可视化区分
