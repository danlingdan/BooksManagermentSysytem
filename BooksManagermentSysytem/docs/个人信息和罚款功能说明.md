# 个人信息和我的罚款功能实现说明

## 功能概述

为图书管理系统的读者用户实现了两个重要功能模块：
1. **个人信息**（PersonalInfoControl）
2. **我的罚款**（MyFinesControl）

## 一、个人信息功能（PersonalInfoControl.cs）

### 功能特性

#### 1. 借书证信息展示
- **借书证号**：显示读者的唯一借书证编号
- **读者姓名**：显示读者真实姓名
- **读者类型**：本校学生/本校教师/校外人员
- **单位/学院**：所属单位信息
- **学号/工号**：学生学号或教师工号
- **开始日期**：借书证办理日期
- **到期日期**：借书证有效期截止日期
- **证件状态**：正常/注销/挂失/补办中（带颜色标识）

#### 2. 当前借阅信息
显示读者当前未归还的图书，包括：
- 馆藏码
- 书名
- 借阅日期
- 应还日期
- 剩余天数
- 状态（正常/即将到期/逾期）

**状态颜色标识：**
- 逾期：红色背景
- 即将到期（≤2天）：黄色背景
- 正常：默认背景

#### 3. 借阅历史
显示最近10条借阅记录：
- 馆藏码
- 书名
- 借阅日期
- 归还日期
- 状态（未归还/正常归还/逾期归还）

#### 4. 智能提醒
- **到期提醒**：借书证到期前30天内提示续期
- **逾期提醒**：有逾期图书时自动弹出警告
- **借阅规则**：显示借阅限制和规则

## 二、我的罚款功能（MyFinesControl.cs）

### 功能特性

#### 1. 罚款统计汇总
- **未支付金额**：红色高亮显示
- **已支付金额**：绿色显示
- **总计金额**：灰色显示

#### 2. 罚款列表
显示罚款详细记录：
- 罚款原因
- 金额
- 状态（未支付/已支付）
- 创建时间

#### 3. 罚款筛选
- 全部罚款
- 仅未支付
- 仅已支付

#### 4. 智能提醒
- **未支付提醒**：有未支付罚款时红色警告
- **状态良好**：无未支付罚款时绿色提示
- **罚款说明**：显示罚款计算规则

### 罚款计算规则
根据 BusinessRules.cs 中的定义：
- **逾期罚款** = 书价 × 0.1 + 逾期天数 × 0.1
- **损坏赔偿** = 书价 × 50%
- **丢失赔偿** = 书价 × 100%

## 三、集成到主界面

### 菜单位置
两个功能都位于"读者服务"菜单下：

```
读者服务
├─ 个人信息      ← PersonalInfoControl
├─ 借阅图书
├─ 归还图书
├─ 预约图书
└─ 我的罚款      ← MyFinesControl
```

## 四、数据库查询

### 个人信息查询
```sql
-- 借书证信息
SELECT r.cardID, r.readername, r.readertype, r.unit, r.number,
       rc.startdate, rc.overdate, rc.state
FROM reader r
INNER JOIN readcard rc ON r.cardID = rc.cardID
WHERE r.cardID = @cardID

-- 当前借阅
SELECT bb.bookID, bib.bibliography_name, bb.borrowdate,
       DATEADD(DAY, 7, bb.borrowdate) AS 应还日期,
       状态标识
FROM bookborrow bb
INNER JOIN BOOK_ITEM bi ON bb.bookID = bi.item_barcode
INNER JOIN BIBLIOGRAPHY bib ON bi.bibliography_id = bib.bibliography_id
WHERE bb.cardID = @cardID AND bb.overdate IS NULL

-- 借阅历史（最近10条）
SELECT TOP 10 bb.bookID, bib.bibliography_name, 
       bb.borrowdate, bb.overdate, 状态
FROM bookborrow bb
...
ORDER BY bb.borrowdate DESC
```

### 我的罚款查询
```sql
SELECT fine_id, reason, amount, fine_status, created_time
FROM fine
WHERE cardID = @cardID
[AND fine_status = N'未支付']  -- 可选筛选
ORDER BY created_time DESC
```

## 九、维护说明

### 数据库依赖
- `reader` 表：读者基本信息
- `readcard` 表：借书证信息
- `bookborrow` 表：借阅明细
- `fine` 表：罚款记录
- `BOOK_ITEM` 表：馆藏信息
- `BIBLIOGRAPHY` 表：书目信息

### 业务规则依赖
- `BorrowRules` 类：借阅规则（最大借阅数、借期等）
- `FineCalculator` 类：罚款计算逻辑
- `CardStateHelper` 类：借书证状态辅助方法

### 服务依赖
- `AuthenticationService`：用户身份认证
- `DatabaseHelper`：数据库访问
