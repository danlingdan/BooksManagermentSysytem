## 🎯 功能特性

### 1. 下拉选择
- 点击下拉箭头显示所有可选的借书证
- 每个选项显示格式: `BRW-YYYY-X-XXXXXX - 读者姓名 (读者类型)`
- 例如: `BRW-2025-1-000001 - 张三 (本校学生)`

### 2. 手动输入
- 支持直接输入借书证号
- 输入时会自动匹配和提示
- 兼容旧的输入习惯

### 3. 自动完成
- 设置了 `AutoCompleteMode.SuggestAppend`
- 输入时自动显示匹配的选项
- 提高输入效率

### 4. 智能筛选
- 根据使用场景选择显示范围:
  - 借阅/归还: 只显示正常状态的借书证
  - 查询/管理: 显示所有状态的借书证

### 5. 自动填充
- 读者登录时自动选中当前用户的借书证
- 无需手动选择
