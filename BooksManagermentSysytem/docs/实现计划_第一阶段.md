# 第一阶段实现计划：核心流通功能

## 目标
实现图书借阅、还书、续借的核心业务流程，这是图书馆系统最关键的功能。

---

## Week 1-2: 图书借阅核心流程

### 1. 数据库准备
**任务：**
- ✅ 确认 `bookborrow` 表结构完整性
- ✅ 确认 `borrow_record` 表结构完整性
- ⚠️ **新增**：创建 `reader_borrow_rules` 表（读者类型借阅规则）
- ⚠️ **新增**：创建 `reader_penalty_rules` 表（读者类型处罚规则）

**SQL 脚本示例：**
```sql
-- 读者借阅规则表
CREATE TABLE dbo.reader_borrow_rules(
    rule_id INT IDENTITY(1,1) PRIMARY KEY,
    reader_type NVARCHAR(10) NOT NULL UNIQUE,  -- 本校学生/本校教师/校外人员
    max_borrow_count INT NOT NULL,             -- 最大借阅数量
    borrow_period_days INT NOT NULL,           -- 借阅期限（天）
    max_renew_count INT NOT NULL,              -- 最大续借次数
    renew_period_days INT NOT NULL,            -- 续借延长天数
    allowed_book_types NVARCHAR(200) NULL,     -- 允许借阅的图书类型（用逗号分隔）
    created_time DATETIME2(0) NOT NULL DEFAULT(SYSDATETIME()),
    updated_time DATETIME2(0) NULL,
    CONSTRAINT CK_reader_borrow_rules_type CHECK (reader_type IN (N'本校学生', N'本校教师', N'校外人员'))
);

-- 读者处罚规则表
CREATE TABLE dbo.reader_penalty_rules(
    rule_id INT IDENTITY(1,1) PRIMARY KEY,
    reader_type NVARCHAR(10) NOT NULL UNIQUE,
    overdue_fine_per_day DECIMAL(10,2) NOT NULL,     -- 逾期罚款（元/天）
    damage_compensation_rate DECIMAL(5,2) NOT NULL,  -- 损坏赔偿比例（0-1）
    lost_compensation_rate DECIMAL(5,2) NOT NULL,    -- 丢失赔偿比例（通常为1.0）
    created_time DATETIME2(0) NOT NULL DEFAULT(SYSDATETIME()),
    updated_time DATETIME2(0) NULL,
    CONSTRAINT CK_reader_penalty_rules_type CHECK (reader_type IN (N'本校学生', N'本校教师', N'校外人员'))
);

-- 插入默认借阅规则
INSERT INTO dbo.reader_borrow_rules (reader_type, max_borrow_count, borrow_period_days, max_renew_count, renew_period_days)
VALUES 
(N'本校学生', 10, 30, 2, 15),
(N'本校教师', 20, 60, 3, 30),
(N'校外人员', 5, 14, 1, 7);

-- 插入默认处罚规则
INSERT INTO dbo.reader_penalty_rules (reader_type, overdue_fine_per_day, damage_compensation_rate, lost_compensation_rate)
VALUES 
(N'本校学生', 0.10, 0.50, 1.00),
(N'本校教师', 0.20, 0.50, 1.00),
(N'校外人员', 0.50, 0.80, 1.50);
```

### 2. 服务层实现
**文件：** `BooksManagermentSysytem\src\Services\BorrowService.cs`

**功能清单：**
- `ValidateBorrowEligibility(cardID, bookID)` - 校验借阅资格
  - 检查读者状态（借书证是否有效）
  - 检查当前借阅数量是否超限
  - 检查是否有未支付罚款
  - 检查图书状态（是否可借）
  
- `CreateBorrowRecord(cardID, bookID)` - 创建借阅记录
  - 创建 `borrow_record` 单头
  - 创建 `bookborrow` 明细
  - 自动计算应还日期（依据借阅规则）
  - 更新图书状态（AVAILABLE → BORROWED）
  - 更新库存数量

- `GetBorrowRules(readerType)` - 获取借阅规则
- `CalculateDueDate(borrowDate, readerType)` - 计算应还日期

## Week 3-4: 图书还书与罚款处理

### 1. 服务层扩展
**文件：** `BooksManagermentSysytem\src\Services\ReturnService.cs`

**功能清单：**
- `ProcessReturn(bookID, condition)` - 处理还书

  - 检查图书完整性
  - 计算逾期天数
  - 自动生成罚款（如果逾期）

- `CalculateOverdueFine(borrowRecord)` - 计算逾期罚款
- `RecordDamageFine(bookID, damageLevel)` - 记录损坏罚款

## Week 5-6: 续借与预约管理

### 1. 续借功能
**服务层：** `BooksManagermentSysytem\src\Services\RenewService.cs`

**功能清单：**
- `ValidateRenewEligibility(bookborrowId)` - 校验续借资格
  - 检查是否已达续借次数上限
  - 检查是否有人预约此书
  - 检查是否逾期
  
- `ProcessRenew(bookborrowId)` - 执行续借
  - 更新应还日期
  - 记录续借次数
  - 记录续借时间

**数据库扩展：**
```sql
-- 为 bookborrow 表添加续借字段
ALTER TABLE dbo.bookborrow 
ADD renew_count INT NOT NULL DEFAULT(0),
    last_renew_time DATETIME2(0) NULL;
```

---

### 2. 预约功能
**服务层：** `BooksManagermentSysytem\src\Services\ReservationService.cs`

**功能清单：**
- `CreateReservation(cardID, bookID, type)` - 创建预约
  - 校验预约资格
  - 计算预约过期时间
  - 创建预约记录
  - 更新图书状态（如果需要）

- `ProcessReservationPickup(reservationId)` - 处理预约取书
  - 更新预约状态（PENDING → FULFILLED）
  - 转为正常借阅流程

- `CancelReservation(reservationId)` - 取消预约
- `CheckExpiredReservations()` - 检查过期预约（定时任务）
