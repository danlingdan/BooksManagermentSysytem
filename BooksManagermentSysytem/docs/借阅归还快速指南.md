# 借阅归还功能快速指南

## 借阅功能

### 借阅规则
- 最多借 **3本书**，最多 **2个分类**
- 借期 **7天**
- 工具书不可外借

### 借阅条件
- ✅ 借书证状态正常且未过期
- ✅ 无未支付罚款
- ✅ 无逾期未还书籍
- ✅ 当前借阅数 < 3本

### 操作流程
1. 输入借书证号 → 查询
2. 扫描图书条码 → 添加（最多3本）
3. 确认借阅 → 完成

---

## 归还功能

### 归还状态
1. **完好** - 无罚款（按时归还）
2. **轻微破损** - 罚款 = 书价×25%
3. **严重破损** - 罚款 = 书价×50%
4. **丢失** - 罚款 = 书价×100%

### 逾期罚款
```
罚款 = 书价×10% + 逾期天数×0.1元
```

**示例**：书价¥50，逾期5天 → 罚款 = 5 + 0.5 = **¥5.50**

### 操作流程
1. 输入借书证号 → 查询已借书籍
2. 选择要归还的书
3. 选择归还状态（完好/轻微破损/严重破损/丢失）
4. 系统显示预计罚款
5. 确认归还 → 完成
