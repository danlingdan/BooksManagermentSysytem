## 修改模式

对于每个文件,按以下步骤修改:

### 步骤1: 添加using引用
```csharp
using BooksManagermentSysytem.Helpers;
```

### 步骤2: 在InitializeComponent方法中
将:
```csharp
this.txtCardID = new System.Windows.Forms.TextBox();
```
替换为:
```csharp
this.cboCardID = new System.Windows.Forms.ComboBox();
```

将:
```csharp
this.txtCardID.Location = new System.Drawing.Point(X, Y);
this.txtCardID.Size = new System.Drawing.Size(W, H);
```
替换为:
```csharp
this.cboCardID.Location = new System.Drawing.Point(X, Y);
this.cboCardID.Size = new System.Drawing.Size(W, H+3);  // ComboBox通常高一点
```

### 步骤3: 更新字段声明
将:
```csharp
private System.Windows.Forms.TextBox txtCardID;
```
替换为:
```csharp
private System.Windows.Forms.ComboBox cboCardID;
```

### 步骤4: 在Load事件中初始化
添加:
```csharp
CardIDSelector.InitializeCardIDComboBox(cboCardID, onlyNormal: true, allowEmpty: true);
```

参数说明:
- `onlyNormal: true` - 只显示状态正常的借书证
- `onlyNormal: false` - 显示所有借书证(包括注销、挂失等)
- `allowEmpty: true` - 允许空选项(用于查询)
- `allowEmpty: false` - 不允许空选项(用于必填场景)

### 步骤5: 获取借书证号
将所有:
```csharp
txtCardID.Text.Trim()
```
或
```csharp
txtCardID.Text
```
替换为:
```csharp
CardIDSelector.GetSelectedCardID(cboCardID)
```

### 步骤6: 设置借书证号
将:
```csharp
txtCardID.Text = cardID;
```
替换为:
```csharp
CardIDSelector.SetSelectedCardID(cboCardID, cardID);
```

### 步骤7: 清空借书证号
将:
```csharp
txtCardID.Clear();
```
或
```csharp
txtCardID.Text = "";
```
替换为:
```csharp
CardIDSelector.SetSelectedCardID(cboCardID, "");
```

### 步骤8: 刷新数据(可选)
如果需要刷新借书证列表:
```csharp
CardIDSelector.RefreshCardIDs(cboCardID, onlyNormal: true, allowEmpty: true);
```

### 步骤9: 按类型筛选(可选)
如果有读者类型筛选功能:
```csharp
CardIDSelector.FilterByReaderType(cboCardID, readerType, onlyNormal: true, allowEmpty: true);
```

## 特殊情况处理

### CardManagementControl.cs
**重要**: 只修改"借书证列表"查询页面,**不要修改**"新办理"页面!

在"借书证列表"的查询面板中:
- 将查询框的txtSearchCardID改为cboSearchCardID
- 使用 `allowEmpty: true` 允许空值查询

在"新办理"面板中:
- **保持所有TextBox不变**
- 不做任何修改

### Reports文件
查询报表通常需要:
- `onlyNormal: false` - 允许查询所有状态的借书证
- `allowEmpty: true` - 允许空值进行全局查询
