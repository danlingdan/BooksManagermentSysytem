### 问题1: SQL注入漏洞 - DeleteMessages方法
**位置**: `Services/NotificationService.cs` 第 246-256 行  
**严重等级**: 🔴 严重  
**优先级**: P0

#### 问题描述
```csharp
public int DeleteMessages(List<long> messageIds)
{
    // ...
    string ids = string.Join(",", messageIds);
    string sql = $@"
        UPDATE system_message 
        SET status = N'Deleted' 
        WHERE message_id IN ({ids})";  // ⚠️ SQL注入！
    
    return DatabaseHelper.ExecuteNonQuery(sql);
}
```

**风险**: 
- 虽然 `messageIds` 是 `long` 类型（降低风险），但仍不符合最佳实践
- 如果 MessageID 来自用户输入，存在被篡改的风险
- 没有使用参数化查询

**修复建议**:
```csharp
public int DeleteMessages(List<long> messageIds)
{
    if (messageIds == null || messageIds.Count == 0)
        return 0;

    try
    {
        // 使用参数化查询
        string placeholders = string.Join(",", messageIds.Select((_, i) => $"@id{i}"));
        string sql = $@"
            UPDATE system_message 
            SET status = N'Deleted' 
            WHERE message_id IN ({placeholders})";

        var parameters = new List<SqlParameter>();
        for (int i = 0; i < messageIds.Count; i++)
        {
            parameters.Add(DatabaseHelper.CreateParameter($"@id{i}", messageIds[i]));
        }

        return DatabaseHelper.ExecuteNonQuery(sql, parameters.ToArray());
    }
    catch
    {
        return 0;
    }
}
```

### 问题3: 硬编码字符串值导致类型转换失败
**位置**: `Services/NotificationService.cs` 第 99-114 行  
**严重等级**: 🔴 严重  
**优先级**: P0

#### 问题描述
MessageType 和 MessagePriority 枚举在数据库中存储为字符串，但枚举名称可能不匹配：

```csharp
public long CreateMessageFromTemplate(...)
{
    DataRow row = dt.Rows[0];
    string title = ReplaceTemplate(row["title_template"].ToString(), parameters);
    string content = ReplaceTemplate(row["content_template"].ToString(), parameters);
    
    // ⚠️ 如果DB中存储的是 "OVERDUE_REMINDER"，但枚举是 "OverdueReminder"，会失败
    MessageType messageType = ParseMessageType(row["message_type"].ToString());
    MessagePriority priority = ParsePriority(row["priority"].ToString());
}

private MessageType ParseMessageType(string typeString)
{
    try
    {
        return (MessageType)Enum.Parse(typeof(MessageType), typeString);  // 大小写敏感！
    }
    catch
    {
        return MessageType.System;
    }
}
```

**风险**:
- Enum.Parse 默认大小写敏感
- 数据库存储与代码枚举名称必须完全一致
- 如果不匹配，会默认返回 MessageType.System，导致消息类型丢失

**建议修复**:
```csharp
private MessageType ParseMessageType(string typeString)
{
    try
    {
        // 使用大小写不敏感的解析
        return (MessageType)Enum.Parse(typeof(MessageType), typeString, ignoreCase: true);
    }
    catch
    {
        return MessageType.System;
    }
}

private MessagePriority ParsePriority(string priorityString)
{
    try
    {
        return (MessagePriority)Enum.Parse(typeof(MessagePriority), priorityString, ignoreCase: true);
    }
    catch
    {
        return MessagePriority.Normal;
    }
}
```

**测试方案**:
- 在 message_template 表中插入测试数据
- 验证各种大小写组合的类型字符串能否正确转换

public static int ProcessAllOverdueReminders()
{
    try
    {
        // 一次性查询所有今天已发送的提醒
        string todayRemindersSQL = @"
            SELECT CONCAT(cardID, '|', bookID) AS key
            FROM overdue_reminder_log
            WHERE CAST(reminder_time AS DATE) = CAST(GETDATE() AS DATE)";
        
        DataTable todayReminders = DatabaseHelper.ExecuteQuery(todayRemindersSQL);
        HashSet<string> sentToday = new HashSet<string>(
            todayReminders.AsEnumerable().Select(r => r["key"].ToString())
        );

        // 查询逾期书籍，一次性加载所有数据
        string overdueSQL = @"...";
        DataTable overdueBooks = DatabaseHelper.ExecuteQuery(overdueSQL);

        int count = 0;
        foreach (DataRow row in overdueBooks.Rows)
        {
            string cardID = row["cardID"].ToString();
            string bookID = row["bookID"].ToString();
            string key = $"{cardID}|{bookID}";

            // 在内存中检查（而不是查询数据库）
            if (sentToday.Contains(key))
            {
                continue;  // 已发送过，跳过
            }

            if (CreateOverdueReminder(row, overdueDays))
            {
                count++;
            }
        }

        return count;
    }
    catch (Exception ex)
    {
        Debug.WriteLine($"处理逾期提醒失败: {ex.Message}");
        return 0;
    }
}

### 问题11: 缓存策略过于简单
**位置**: `BusinessRules.cs` 第 13-23 行  
**严重等级**: 🟡 中  
**优先级**: P3

#### 问题描述
使用基于时间的缓存，但没有考虑并发修改：

```csharp
private static Dictionary<string, BorrowRule> ruleCache = 
    new Dictionary<string, BorrowRule>();
private static DateTime lastCacheTime = DateTime.MinValue;
private const int CacheMinutes = 10;

private static void RefreshCacheIfNeeded()
{
    if ((DateTime.Now - lastCacheTime).TotalMinutes > CacheMinutes)
    {
        ruleCache.Clear();
        lastCacheTime = DateTime.Now;
    }
}
```

**问题**:
- 如果规则在缓存中被修改，用户会看到过期数据（最多10分钟）
- 没有缓存失效机制，管理员修改规则后必须等待10分钟才生效
- `Dictionary<T>` 在多线程场景下不安全

**修复建议**:
```csharp
private static readonly object _cacheLock = new object();
private static Dictionary<string, BorrowRule> ruleCache = 
    new Dictionary<string, BorrowRule>();
private static DateTime lastCacheTime = DateTime.MinValue;
private const int CacheMinutes = 10;

public static void ClearCache()
{
    lock (_cacheLock)
    {
        ruleCache.Clear();
        lastCacheTime = DateTime.MinValue;
    }
}

private static void RefreshCacheIfNeeded()
{
    lock (_cacheLock)
    {
        if ((DateTime.Now - lastCacheTime).TotalMinutes > CacheMinutes)
        {
            ruleCache.Clear();
            lastCacheTime = DateTime.Now;
        }
    }
}

public static BorrowRule GetRuleByReaderType(string readerType)
{
    lock (_cacheLock)
    {
        RefreshCacheIfNeeded();
        if (ruleCache.ContainsKey(readerType))
        {
            return ruleCache[readerType];
        }
    }

    // 在锁之外进行数据库查询
    try
    {
        string sql = "EXEC sp_GetBorrowRuleByReaderType @reader_type";
        DataTable dt = DatabaseHelper.ExecuteQuery(sql,
            DatabaseHelper.CreateParameter("@reader_type", readerType));

        if (dt.Rows.Count > 0)
        {
            var rule = MapFromDataRow(dt.Rows[0]);
            
            lock (_cacheLock)
            {
                ruleCache[readerType] = rule;
            }
            return rule;
        }
    }
    catch
    {
        // ...
    }

    return GetDefaultRule(readerType);
}
```

### 问题13: 缺少返回值验证

public class AnnouncementResult
{
    public int SuccessCount { get; set; }
    public int FailureCount { get; set; }
    public string ErrorMessage { get; set; }
}

public AnnouncementResult CreateAnnouncement(string title, string content, 
    MessagePriority priority = MessagePriority.Normal)
{
    var result = new AnnouncementResult();

    try
    {
        // ...
        foreach (DataRow row in readers.Rows)
        {
            string cardID = row["cardID"].ToString();
            if (CreateMessage(cardID, MessageType.Announcement, title, content, priority) > 0)
            {
                result.SuccessCount++;
            }
            else
            {
                result.FailureCount++;
            }
        }
    }
    catch (Exception ex)
    {
        result.ErrorMessage = ex.Message;
    }

    return result;
}
