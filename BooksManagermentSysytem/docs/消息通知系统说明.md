# 消息通知系统和逾期自动提醒功能说明

## 📋 功能概述

本次更新实现了**消息通知系统**和**逾期自动提醒**两大核心功能，为图书管理系统提供了统一的消息中心和自动化提醒机制。

---

## ✨ 主要功能

### 1. 消息通知系统（NotificationService）

#### 功能特性
- ✅ 统一的消息中心，支持多种消息类型
- ✅ 消息分类管理（系统消息、逾期提醒、预约通知、罚款通知等）
- ✅ 消息优先级（低、普通、高、紧急）
- ✅ 消息状态管理（未读、已读、已删除）
- ✅ 消息模板支持，便于标准化消息内容
- ✅ 批量操作（标记全部已读、批量删除）

#### 支持的消息类型
| 消息类型 | 说明 | 优先级 |
|---------|------|-------|
| System | 系统消息 | 普通 |
| OverdueReminder | 逾期提醒 | 高 |
| SoonDueReminder | 即将到期提醒 | 普通 |
| ReservationReady | 预约到书通知 | 普通 |
| ReservationExpired | 预约过期通知 | 低 |
| FineNotice | 罚款通知 | 高 |
| CardExpireReminder | 借书证到期提醒 | 普通 |
| Announcement | 系统公告 | 普通 |

---

### 2. 逾期自动提醒（OverdueReminderService）

#### 功能特性
- ✅ 自动检测逾期图书（每日运行）
- ✅ 即将到期提醒（提前3天通知）
- ✅ 逾期罚款预估（实时计算）
- ✅ 借书证到期提醒（提前30天通知）
- ✅ 防重复发送（同一天不重复发送相同提醒）
- ✅ 提醒历史记录（可查询）

#### 提醒规则
```
即将到期：应还日期前 3 天开始提醒
已逾期：每天检测并发送提醒
借书证到期：到期前 30 天开始提醒
```

#### 罚款计算规则
```
逾期罚款 = 书价 × 10% + 逾期天数 × ¥0.10
```

| message_id | BIGINT | 消息ID（主键） |

| message_type | NVARCHAR(30) | 消息类型 |
| title | NVARCHAR(200) | 消息标题 |
| content | NVARCHAR(MAX) | 消息内容 |

| related_id | NVARCHAR(50) | 关联ID |

### 2. overdue_reminder_log（逾期提醒记录表）

| 字段 | 类型 | 说明 |

| 字段 | 类型 | 说明 |

| content_template | NVARCHAR(MAX) | 内容模板 |

## 🎯 使用方法

### 1. 初始化数据库表

运行SQL脚本创建表结构：

```bash
执行文件：BooksManagermentSysytem\sql\notification_tables.sql
```

### 2. 读者查看消息

```csharp
// 读者登录后，系统自动加载消息中心控件
// 位置：主界面 → 消息中心

// 显示功能：
// - 查看所有消息
// - 筛选未读消息
// - 标记已读
// - 删除消息
```

### 3. 管理员发送系统公告

```csharp
// 使用NotificationService创建公告
int count = NotificationService.Instance.CreateAnnouncement(
    "图书馆春节放假通知",
    "春节期间（2月1日-2月7日）图书馆闭馆，请合理安排借还书时间。",
    MessagePriority.High
);
```

### 4. 手动触发逾期提醒（可选）

```csharp
// 处理所有逾期和即将逾期的图书
int count = OverdueReminderService.ProcessAllOverdueReminders();

// 处理借书证到期提醒
int cardReminders = OverdueReminderService.ProcessCardExpireReminders(30);
```

## 📝 代码示例

### 示例1：创建逾期提醒消息

```csharp
// 系统自动调用（定时任务）
var parameters = new Dictionary<string, string>
{
    { "BookName", "活着" },
    { "OverdueDays", "5" },
    { "DueDate", "2025-01-20" },
    { "EstimatedFine", "5.50" }
};

long messageId = NotificationService.Instance.CreateMessageFromTemplate(
    "BRW-2025-1-000001", 
    "OVERDUE_REMINDER", 
    parameters, 
    "BK-000001", 
    "BookBorrow"
);
```

### 示例2：查询未读消息数量

```csharp
string cardID = "BRW-2025-1-000001";
int unreadCount = NotificationService.Instance.GetUnreadCount(cardID);
Console.WriteLine($"您有 {unreadCount} 条未读消息");
```

### 示例3：获取消息列表

```csharp
string cardID = "BRW-2025-1-000001";

// 获取所有消息（包括已读）
DataTable allMessages = NotificationService.Instance.GetMessages(cardID, true);

// 仅获取未读消息
DataTable unreadMessages = NotificationService.Instance.GetMessages(cardID, false);

// 获取最近10条消息
DataTable recentMessages = NotificationService.Instance.GetMessages(cardID, true, 10);
```

## 🐛 故障排查

### 问题1：消息未显示
**解决方法**：
1. 检查数据库表是否正确创建
2. 确认用户已登录且有借书证号
3. 检查SQL查询是否执行成功

### 问题2：逾期提醒未发送
**解决方法**：
1. 手动调用`ProcessAllOverdueReminders()`测试
2. 检查`bookborrow`表中是否有逾期记录
3. 查看`overdue_reminder_log`表确认是否已记录

### 问题3：消息模板不生效
**解决方法**：
1. 确认`message_template`表中有数据
2. 检查`is_active`字段是否为1
3. 验证模板代码是否正确
