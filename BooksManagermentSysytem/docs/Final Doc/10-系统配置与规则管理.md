## 2. 借阅规则管理

### 2.1 规则配置界面

详见《借阅规则表》相关设置

**关键规则参数**：

```sql
SELECT * FROM BORROW_RULES
WHERE is_active = 1
```

### 2.2 规则应用流程

```
读者借书
    ↓
查询读者类型
    ↓
加载对应的BORROW_RULES
    ├─ max_borrow_count：最大借数
    ├─ borrow_days：借期
    ├─ max_renew_count：最大续借次数
    └─ allow_reference_books：是否允许借工具书
    ↓
根据规则检查和限制
    ├─ 检查当前借数是否超限
    ├─ 检查是否可借特定类型
    └─ 计算应还日期
    ↓
执行借阅
```

### 2.3 规则修改与生效

```
编辑规则参数
    ↓
保存新规则
    ↓
立即生效（对新的借阅操作）
    ↓
对现有借阅的影响：
    ├─ 已借出图书：不影响
    ├─ 新的借阅操作：按新规则
    └─ 续借和预约：按新规则
```

## 3. 罚款规则管理

### 3.1 规则配置界面

详见《罚款规则表》相关设置

**关键规则参数**：

```sql
SELECT * FROM FINE_RULES
WHERE is_active = 1
```

### 3.2 规则组成

```
逾期罚款规则
├─ overdue_price_rate：书价系数
├─ overdue_day_rate：日系数
├─ max_overdue_fine：最大逾期罚款
└─ free_overdue_days：免罚天数

破损赔偿规则
├─ damaged_rate：严重破损系数
├─ minor_damaged_rate：轻微破损系数
└─ lost_rate：丢失赔偿系数

限制条件
├─ max_total_fine：最大总罚款
└─ is_active：是否启用
```

### 3.3 规则应用

```
图书归还
    ↓
根据读者类型加载FINE_RULES
    ↓
根据归还状态计算罚款
    ├─ 完好：计算逾期罚款
    ├─ 破损：计算破损赔偿或逾期罚款（取大者）
    └─ 丢失：全额赔偿
    ↓
应用最大罚款限制
    ↓
生成罚款记录
```

## 5. 通知与提醒配置

### 5.1 通知模板

系统支持自定义通知模板：

```
模板类型：逾期提醒
标题：【图书馆】图书逾期提醒
内容：尊敬的读者，您借阅的《{book_name}》已逾期{overdue_days}天，
      请于24小时内归还，否则将按规定收取罚款。
      应还日期：{due_date}
      
模板变量：
{reader_name} - 读者姓名
{book_name} - 图书名称
{overdue_days} - 逾期天数
{due_date} - 原应还日期
{fine_amount} - 罚款金额
```

### 5.2 通知规则配置

```
├─ 逾期提醒
│   ├─ 触发时间：逾期1天后
│   ├─ 通知方式：短信/邮件
│   └─ 发送频率：每天一次
│
├─ 预约到货提醒
│   ├─ 触发时间：图书归还时
│   ├─ 通知方式：短信/邮件
│   └─ 有效期：3天
│
└─ 证件即将过期提醒
    ├─ 触发时间：到期前30天
    ├─ 通知方式：邮件
    └─ 提醒频率：1次
```

## 9. 故障恢复

### 9.1 备份恢复流程

```
发现故障
    ↓
确定故障类型和影响范围
    ↓
选择合适的备份点
    ↓
执行恢复操作
    ├─ 完整恢复：恢复完整备份
    ├─ 差分恢复：加载差分备份
    └─ 日志恢复：应用日志备份
    ↓
验证恢复数据完整性
    ↓
启动系统恢复服务
```

### 9.2 数据验证

```sql
-- 检查主外键完整性
SELECT COUNT(*) FROM reader
WHERE cardID NOT IN (SELECT cardID FROM readcard)

-- 检查借阅记录一致性
SELECT COUNT(*) FROM bookborrow
WHERE borrow_record_id NOT IN (SELECT borrow_record_id FROM borrow_record)
```
