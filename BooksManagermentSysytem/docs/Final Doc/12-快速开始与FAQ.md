## 1. 快速开始

### 1.1 首次启动

#### 步骤1：准备系统环境

```
□ 安装 .NET Framework 4.8
□ 安装 SQL Server 2016 或更高版本
□ 验证网络连接
□ 准备至少500GB硬盘空间
```

#### 步骤2：部署数据库

```
1. 打开 SQL Server Management Studio
2. 连接到本地数据库
3. 新建查询窗口
4. 依次执行初始化脚本：
   - database.sql
   - schema_extensions.sql
   - permission_system.sql
   - create_rules_tables.sql
   - init_rules_data.sql
   - renew_reservation_extensions.sql
5. 验证表创建成功
```

#### 步骤3：配置应用

```
1. 编辑 App.config
2. 修改连接字符串：
   <connectionStrings>
     <add name="LibraryDB" 
          connectionString="Server=localhost;Database=LibraryDB;User Id=AppUser;Password=YourPassword;" />
   </connectionStrings>
3. 保存文件
```

#### 步骤4：启动应用

```
1. 双击 BooksManager.exe
2. 使用默认账户登录：
   用户名：admin
   密码：admin@123
3. 修改密码（首次登录后强制要求）
4. 完成
```

### 1.2 常见首次配置

#### 1.2.1 添加图书馆基本信息

```
1. 登录系统 → 系统管理 → 系统配置
2. 修改以下信息：
   - 图书馆名称
   - 图书馆电话
   - 管理员邮箱
3. 保存配置
```

#### 1.2.2 创建管理员账户

```
1. 系统管理 → 用户管理
2. 新增用户
3. 填写信息：
   - 用户名：librarian001
   - 密码：临时密码（用户首次登录后强制修改）
   - 角色：Librarian
   - 显示名称：某某图书馆员
4. 保存
```

#### 1.2.3 初始化分类和库位

```
1. 编目管理 → 分类管理
2. 导入默认分类
   - 使用系统预设的中图法分类
3. 库位管理 → 新增库位
4. 创建基本库位结构：
   - 一楼 → A区 → 01排 → ...
   - 热门区 → 01号架
   - 新书区 → 01号架
   - ...
```

## 2. 常见问题FAQ

### 2.1 登录相关问题

**Q1：忘记密码怎么办？**

A：
```
1. 联系系统管理员
2. 管理员在系统中重置密码
3. 首次登录后强制修改密码
```

**Q2：登录显示"用户不存在"？**

A：
```
检查项：
- 用户名是否正确（区分大小写）
- 账户是否被禁用（系统管理 → 用户管理）
- 借书证号是否有效（仅限读者账户）
```

**Q3：为什么会话超时？**

A：
```
原因：30分钟内无操作
解决方案：
- 重新登录
- 如需长时间不操作，可注销后重新登录
```

### 2.2 借书相关问题

**Q4：为什么无法借书？**

A：检查以下几点：
```
□ 借书证是否有效？
  系统 → 读者管理 → 查询借书证 → 检查状态
  
□ 是否超过借数限制？
  当前界面显示"已借 X/Y 本"
  
□ 是否有逾期书籍？
  如有逾期，需先归还
  
□ 是否有罚款未支付？
  有罚款会被警告，但通常仍可借书
  
□ 图书是否可借？
  工具书仅馆内浏览，不能外借
```

**Q5：如何查看应还日期？**

A：
```
1. 借书时，会在借书凭条上显示
2. 登录系统 → 我的借书 → 当前借阅
3. 显示"应还日期"列
```

**Q6：如何办理续借？**

A：
```
1. 借书 → 续借管理
2. 查询借书证
3. 选择要续借的图书
4. 点击"办理续借"
5. 新的应还日期自动显示
```

### 2.3 还书相关问题

**Q7：归还时需要缴纳罚款吗？**

A：
```
取决于图书状态：
- 完好且未逾期：无罚款
- 完好但逾期：需缴逾期罚款
- 破损：需缴破损赔偿
- 丢失：需缴全额赔偿
```

**Q8：如何查看罚款金额？**

A：
```
1. 归还时自动计算并显示
2. 也可查询：我的罚款 → 查看详情
3. 罚款原因和金额列表
```

**Q9：如何缴纳罚款？**

A：
```
支付方式：
1. 前往图书馆办公室现金缴纳
2. 刷卡缴纳
3. 系统中标记缴纳（需操作员确认）
```

### 2.4 预约相关问题

**Q10：如何预约图书？**

A：
```
1. 图书 → 预约管理
2. 搜索要预约的图书
3. 点击"预约"
4. 确认预约信息
5. 预约成功，可在"我的预约"查看
```

**Q11：预约多久能取书？**

A：
```
预约有效期：3天
- 图书归还后立即放入预约书架
- 如3天内未取，自动过期
- 建议尽快取书
```

**Q12：如何取消预约？**

A：
```
1. 图书 → 预约管理 → 我的预约
2. 找到要取消的预约
3. 点击"取消"
4. 确认取消
5. 预约立即取消，其他预约者进入队列
```

### 2.5 读者信息相关问题

**Q13：如何修改个人信息？**

A：
```
限制修改：
- 姓名：不可修改
- 学号/工号：不可修改
- 所属单位：可修改（需联系管理员）
- 联系方式：可自己修改
```

**Q14：借书证过期怎么办？**

A：
```
1. 提前30天会收到续期提醒
2. 前往图书馆办证处办理续期
3. 生成新的借书证号
4. 旧证自动失效
```

**Q15：借书证丢失了怎么办？**

A：
```
1. 立即前往图书馆报告丢失
2. 办理挂失手续
3. 申请补办新证
4. 支付补办费
5. 取得新借书证
```

```
3. 系统性能不足

   → 清理磁盘空间
```

## 3. 应急处理

### 3.1 系统无法启动

**症状**：点击exe无反应或闪退

**处理步骤**：

```
1. 检查 .NET Framework
   开始 → 程序 → 程序和功能
   确认 .NET Framework 4.8 已安装
   
2. 检查 SQL Server 连接
   开始 → SQL Server → SQL Server Management Studio
   测试连接
   
3. 查看错误日志
   开始 → 事件查看器 → Windows日志 → 应用程序
   寻找红色错误信息
   
4. 如以上都正常，联系技术支持
```

### 3.2 数据库无法连接

**症状**：操作时提示"cannot connect to database"

**处理步骤**：

```
1. 验证 SQL Server 是否运行
   任务管理器 → 搜索 sqlservr.exe
   
2. 尝试重启 SQL Server
   控制面板 → 管理工具 → 服务
   找到 SQL Server
   右键 → 重启
   
3. 检查网络连接
   ping localhost
   ping database-server-ip
   
4. 检查防火墙规则
   Windows防火墙 → 检查是否阻止
   
5. 如问题未解决，联系DBA
```

### 3.3 性能严重下降

**症状**：操作响应缓慢，界面卡顿

**处理步骤**：

```
1. 检查系统资源
   任务管理器 → CPU/内存使用率
   如超过80%，重启应用
   
2. 清理缓存
   系统管理 → 系统维护 → 清理缓存
   
3. 数据库维护
   联系 DBA 执行：
   - 索引重建
   - 统计信息更新
   
4. 如问题持续，进行故障诊断
   收集日志并联系技术支持
```

### 3.4 数据意外丢失

**症状**：某些数据突然消失

**处理步骤**：

```
1. 不要继续操作，避免覆盖数据
2. 立即通知系统管理员
3. 从备份恢复
   - 建议恢复到故障前1小时
   - 将损失的数据重新输入
4. 进行故障分析，防止再次发生
```

## 7. 使用建议

### 7.1 最佳实践

```
1. 定期修改密码（每90天）
2. 在固定位置借还书（减少遗失）
3. 及时续借（避免逾期）
4. 妥善保管借书证
5. 定期查看"我的信息"了解状态
6. 遇到问题及时反馈
```

### 7.2 提高效率

```
1. 使用条码扫描枪（提高借还速度）
2. 批量借书（减少次数）
3. 提前预约热门书（避免等待）
4. 利用分类浏览发现新书
5. 参加图书馆举办的活动
```
