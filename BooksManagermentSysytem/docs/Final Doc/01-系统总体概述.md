## 1. 系统简介

### 1.1 系统定位

图书管理系统是一个面向高校、公共图书馆的综合性图书馆业务管理平台，涵盖读者管理、图书编目、借阅归还、罚款管理、统计报表等核心业务流程。

### 1.2 系统目标

- **提高效率**：自动化图书馆日常业务流程，减少人工操作
- **规范管理**：建立标准化的图书分类、编目和借阅规则
- **数据统计**：提供丰富的报表和数据分析功能
- **用户友好**：简洁直观的操作界面，降低学习成本
- **安全可靠**：完善的权限管理和数据审计机制

### 1.3 适用场景

- 高校图书馆
- 公共图书馆
- 企事业单位图书室
- 中小型图书馆

### 2.2 分层设计

#### 表示层 (Presentation Layer)
- **Forms**：登录窗体、主窗体、注册窗体、修改密码窗体
- **Controls**：各功能模块的 UserControl 控件
- **职责**：用户交互、数据展示、输入验证

#### 业务逻辑层 (Business Logic Layer)
- **Services**：封装核心业务逻辑（认证、权限、续借、预约、通知等）
- **BusinessRules**：业务规则定义（借阅规则、罚款规则）
- **职责**：业务流程控制、规则校验、数据处理

#### 数据访问层 (Data Access Layer)
- **DatabaseHelper**：统一的数据库操作接口
- **职责**：SQL 执行、事务管理、连接池管理

#### 数据库层 (Database Layer)
- **表**：数据持久化存储
- **视图**：简化查询、权限控制
- **存储过程**：复杂业务逻辑、性能优化
- **触发器**：数据一致性保证

## 5. 业务流程

### 5.1 读者注册与办证流程

```
开始 → 填写注册信息 → 系统校验 → 自动生成借书证号 
    → 设置有效期（1年）→ 保存读者信息 → 办证成功
```

### 5.2 图书借阅流程

```
开始 → 输入借书证号 → 校验读者资格
    → 扫描图书条码 → 校验图书状态
    → 检查借阅数量限制 → 检查分类限制
    → 计算应还日期 → 创建借阅记录
    → 更新图书状态 → 借阅成功
```

### 5.3 图书归还流程

```
开始 → 输入借书证号 → 查询借阅记录
    → 选择归还图书 → 选择归还状态
    → 计算逾期天数 → 计算罚款金额
    → 更新借阅记录 → 更新图书状态
    → 检查预约队列 → 生成罚款记录（如有）
    → 归还成功
```

### 5.4 图书续借流程

```
开始 → 输入借书证号 → 查询可续借图书
    → 校验续借资格（次数、逾期、预约）
    → 计算新到期日 → 更新续借记录
    → 续借成功
```

### 5.5 图书预约流程

```
开始 → 输入借书证号 → 搜索图书
    → 选择预约类型 → 检查预约限制
    → 创建预约记录 → 计算取书截止时间
    → 预约成功 → 发送通知
```
