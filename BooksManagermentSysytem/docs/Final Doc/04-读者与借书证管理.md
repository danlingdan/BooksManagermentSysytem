## 1. 借书证管理总体设计

### 1.1 借书证号生成规则

借书证号采用统一格式：`BRW-YYYY-T-NNNNNN`

| 部分 | 含义 | 示例 |
|------|------|------|
| BRW | 固定前缀 | BRW |
| YYYY | 年份 | 2025 |
| T | 读者类别码 | 1=学生, 2=教师, 3=校外 |
| NNNNNN | 6位序号 | 000001 |

**示例**：
- `BRW-2025-1-000001`：2025年第一个学生证
- `BRW-2025-2-000101`：2025年第一个教师证
- `BRW-2025-3-000201`：2025年第一个校外证

### 1.2 自动生成流程

```
确定读者类型
    ↓
检索当年该类型最大序号
    ↓
序号 + 1
    ↓
构建完整借书证号
    ↓
验证格式
    ↓
保存到数据库
```

### 1.3 有效期管理

- **默认有效期**：1年
- **计算方式**：`overdate = startdate + 1年`
- **到期提醒**：到期前30天提醒续期
- **续期方式**：前往办证处办理续期（新增证号）

## 3. 借书证生命周期

### 3.1 状态转换

```
申请 → 正常 ⟷ 挂失 → 补办中 → 正常 → 注销
```

### 3.2 各状态说明

| 状态 | 代码 | 说明 | 是否可借书 |
|------|------|------|-----------|
| 正常 | 正常 | 正常使用中 | ✅ 是 |
| 挂失 | 挂失 | 证件已挂失，需补办 | ❌ 否 |
| 补办中 | 补办中 | 办理补办手续中 | ❌ 否 |
| 注销 | 注销 | 证件已注销 | ❌ 否 |

### 3.3 状态转换规则

**正常 → 挂失**
- 条件：读者报告证件遗失
- 操作：点击"挂失"按钮
- 备注：系统阻止该证使用
- 可恢复：可办理补办手续

**挂失 → 补办中**
- 条件：读者提交补办申请
- 操作：点击"申请补办"按钮
- 备注：生成新证号
- 费用：按规定收取补办费

**补办中 → 正常**
- 条件：补办手续完成
- 操作：点击"补办完成"按钮
- 备注：新证号激活，旧证号停用
- 信息：保留原始数据

**正常 → 注销**
- 条件：读者申请注销或被动注销
- 操作：点击"注销"按钮
- 备注：证件和读者记录保留，仅改状态
- 影响：无法借书，保留历史记录

### 4.2 读者信息维护

#### 4.2.1 新增读者

**流程**：
```
填写读者信息
    ↓
选择读者类型
    ↓
系统自动生成借书证号
    ↓
验证信息
    ↓
保存到数据库
    ↓
发放借书证
    ↓
完成
```

**必填字段**：
- 姓名
- 读者类型
- 所属单位

**条件约束**：
- 本校学生/教师必须填学号/工号
- 校外人员不需要学号/工号
- 借书证号自动生成，不能手工输入

#### 4.2.2 修改读者信息

**可修改字段**：
- 姓名
- 所属单位
- 联系电话（可选）
- 电子邮箱（可选）
- 备注

**不可修改字段**：
- 借书证号
- 读者类型
- 学号/工号

#### 4.2.3 查询读者

**查询方式**：
1. 按借书证号查询（精确）
2. 按姓名查询（模糊）
3. 按所属单位查询（精确）
4. 按读者类型查询（精确）
5. 高级组合查询

**查询结果显示**：
- 基本信息
- 借书证状态
- 当前未还书籍
- 未支付罚款
- 借阅历史统计

#### 4.2.4 删除读者

**删除条件**：
- 无未还书籍
- 无未支付罚款
- 借书证处于注销状态

**删除操作**：
- 软删除：标记为已删除
- 保留历史数据
- 记录删除操作日志

## 7. 数据一致性校验

### 7.1 业务规则

#### 7.1.1 借书证号一致性

```sql
-- 借书证号年份必须与办证年份一致
ALTER TABLE readcard
ADD CONSTRAINT CK_readcard_year_match 
CHECK (SUBSTRING(cardID, 5, 4) = CONVERT(CHAR(4), YEAR(startdate)))
```

#### 7.1.2 读者类型匹配

```sql
-- 读者类型必须与证号类别码匹配
ALTER TABLE reader
ADD CONSTRAINT CK_reader_cardid_type_match 
CHECK (
    (readertype = N'本校学生' AND SUBSTRING(cardID,10,1)='1')
    OR (readertype = N'本校教师' AND SUBSTRING(cardID,10,1)='2')
    OR (readertype = N'校外人员' AND SUBSTRING(cardID,10,1)='3')
)
```

#### 7.1.3 学号/工号规则

```sql
-- 本校师生必须有学号/工号，校外人员无
ALTER TABLE reader
ADD CONSTRAINT CK_reader_number_rule 
CHECK (
    (readertype IN (N'本校学生',N'本校教师') AND [number] IS NOT NULL)
    OR
    (readertype = N'校外人员' AND [number] IS NULL)
)
```

### 7.2 验证程序

```csharp
public bool ValidateReaderInfo(Reader reader)
{
    // 1. 验证借书证号格式
    if (!IsValidCardID(reader.CardID))
        throw new ValidationException("借书证号格式不正确");
    
    // 2. 验证读者类型
    if (!IsValidReaderType(reader.ReaderType))
        throw new ValidationException("读者类型无效");
    
    // 3. 验证类型与证号一致性
    if (!IsCardTypeMatched(reader.CardID, reader.ReaderType))
        throw new ValidationException("读者类型与证号不匹配");
    
    // 4. 验证学号/工号
    if (reader.ReaderType != "校外人员" && string.IsNullOrEmpty(reader.Number))
        throw new ValidationException("本校师生必须填写学号/工号");
    
    if (reader.ReaderType == "校外人员" && !string.IsNullOrEmpty(reader.Number))
        throw new ValidationException("校外人员不需要学号/工号");
    
    return true;
}
```

## 8. 常见操作流程

### 8.1 办理新借书证

```
1. 点击"新增借书证"按钮
   ↓
2. 填写读者基本信息
   - 姓名（必填）
   - 读者类型（必填）：本校学生/本校教师/校外人员
   - 所属单位（必填）
   - 学号/工号（本校师生必填）
   ↓
3. 系统自动生成借书证号
   - 格式：BRW-YYYY-T-NNNNNN
   - 自动计算有效期至下一年同日
   ↓
4. 验证信息无误
   ↓
5. 点击"保存"按钮
   ↓
6. 系统保存数据并打印证件
   ↓
7. 办证完成
```

### 8.2 处理证件挂失

```
1. 查询读者借书证
   ↓
2. 找到要挂失的证件
   ↓
3. 点击"挂失"按钮
   ↓
4. 输入挂失原因（可选）
   ↓
5. 系统标记证件状态为"挂失"
   ↓
6. 阻止该证的借阅操作
   ↓
7. 记录操作日志
   ↓
8. 提示读者可申请补办
```

### 8.3 办理证件补办

```
1. 查询挂失的借书证
   ↓
2. 点击"补办"按钮
   ↓
3. 验证补办资格
   - 检查是否有未还书籍
   - 检查是否有未支付罚款
   ↓
4. 收取补办费（如有规定）
   ↓
5. 系统生成新的借书证号
   - 保持原有读者类型
   - 更新有效期
   ↓
6. 旧证号标记为已注销
   ↓
7. 新证号激活可用
   ↓
8. 打印新证件
   ↓
9. 补办完成
```

### 8.4 办理证件注销

```
1. 查询要注销的借书证
   ↓
2. 验证注销条件
   - 无未还书籍
   - 无未支付罚款
   ↓
3. 点击"注销"按钮
   ↓
4. 输入注销原因
   ↓
5. 系统标记证件状态为"注销"
   ↓
6. 保留读者历史数据
   ↓
7. 记录操作日志
   ↓
8. 注销完成
```

## 9. 统计与报表

### 9.1 读者统计

```sql
-- 按读者类型统计
SELECT 
    readertype,
    COUNT(*) AS 总数,
    SUM(CASE WHEN rc.state='正常' THEN 1 ELSE 0 END) AS 有效证,
    SUM(CASE WHEN rc.state='挂失' THEN 1 ELSE 0 END) AS 挂失证,
    SUM(CASE WHEN rc.state='注销' THEN 1 ELSE 0 END) AS 注销证
FROM reader r
INNER JOIN readcard rc ON r.cardID = rc.cardID
GROUP BY readertype
```

### 9.2 证件有效期统计

```sql
-- 即将到期的证件（30天内）
SELECT cardID, readername, overdate
FROM reader r
INNER JOIN readcard rc ON r.cardID = rc.cardID
WHERE rc.state = N'正常'
    AND DATEDIFF(DAY, GETDATE(), rc.overdate) <= 30
    AND DATEDIFF(DAY, GETDATE(), rc.overdate) >= 0
ORDER BY rc.overdate
```

### 9.3 读者活跃度统计

```sql
-- 最近30天借阅情况
SELECT TOP 20
    r.cardID,
    r.readername,
    COUNT(bb.bookborrow_id) AS 借阅次数,
    MAX(bb.borrowdate) AS 最后借阅日期
FROM reader r
LEFT JOIN bookborrow bb ON r.cardID = bb.cardID
    AND DATEDIFF(DAY, bb.borrowdate, GETDATE()) <= 30
GROUP BY r.cardID, r.readername
HAVING COUNT(bb.bookborrow_id) > 0
ORDER BY COUNT(bb.bookborrow_id) DESC
```
