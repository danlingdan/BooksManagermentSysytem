## 1. 数据库总体设计

### 1.1 设计目标

- 支持高校图书馆的完整业务流程
- 数据一致性和完整性保证
- 性能优化和查询效率
- 灵活的规则配置和扩展性

### 1.2 设计原则

- **三范式**：符合数据库设计规范，避免数据冗余
- **完整性约束**：通过外键、检查约束等保证数据有效性
- **索引优化**：为常见查询建立索引以提升性能
- **存储过程**：复杂业务逻辑封装在存储过程中
- **视图**：简化复杂查询，便于数据访问

### 1.3 数据库架构图

```
┌──────────────────────────────────────────────────────────┐
│                   图书管理系统数据库                       │
├──────────────────────────────────────────────────────────┤
│  读者服务                │ 图书管理              │ 系统管理  │
```

## 2. 核心表结构

### 2.1 借书证表 (readcard)

**用途**：管理读者的借书证信息及有效期

| 字段名 | 数据类型 | 约束 | 说明 |
|--------|---------|------|------|
| cardID | NVARCHAR(20) | PK | 借书证号，格式: BRW-年份-类别-序号 |
| startdate | DATE | NOT NULL | 办证日期 |
| overdate | DATE | NOT NULL | 到期日期 (自动计算为startdate+1年) |
| state | NVARCHAR(10) | NOT NULL | 状态: 正常/注销/挂失/补办中 |

**关键约束**：
- 借书证号格式：`BRW-YYYY-T-NNNNNN`
  - YYYY：年份（必须与startdate年份一致）
  - T：类别码（1=学生，2=教师，3=校外）
  - NNNNNN：6位序号
- `overdate = startdate + 1年`
- 状态枚举值控制

**索引**：
```sql
CREATE UNIQUE INDEX UX_readcard_cardID ON readcard(cardID)
```

### 2.2 读者表 (reader)

**用途**：保存读者的个人信息，与readcard一对一绑定

| 字段名 | 数据类型 | 约束 | 说明 |
|--------|---------|------|------|
| cardID | NVARCHAR(20) | PK, FK | 借书证号 |
| readername | NVARCHAR(50) | NOT NULL | 读者姓名 |
| readertype | NVARCHAR(10) | NOT NULL | 读者类型：本校学生/本校教师/校外人员 |
| unit | NVARCHAR(100) | NULL | 所属单位/学院 |
| number | NVARCHAR(30) | NULL | 学号/工号（校外为NULL） |
| borrowed_books_info | NVARCHAR(400) | NULL | 冗余摘要 |
| borroweddate | DATE | NULL | 最近借书日期 |
| borrow_note | NVARCHAR(200) | NULL | 备注 |

**关键约束**：
- `readertype` 与 `cardID` 的类别码一致性
- 本校师生：`number` 非空；校外人员：`number` 为NULL

**索引**：
```sql
CREATE INDEX IX_reader_type ON reader(readertype)
CREATE INDEX IX_reader_unit ON reader(unit)
```

### 2.3 图书分类表 (BOOK_CATEGORY)

**用途**：树形结构存储中图法分类

| 字段名 | 数据类型 | 约束 | 说明 |
|--------|---------|------|------|
| category_id | INT | PK | 分类编号 |
| category_code | NVARCHAR(20) | UNIQUE | 分类号（如I247.5） |
| category_name | NVARCHAR(100) | NOT NULL | 分类名称 |
| parent_category_id | INT | FK | 父分类ID（自引用） |
| Description | NVARCHAR(500) | NULL | 分类说明 |
| create_time | DATETIME2 | DEFAULT | 创建时间 |
| update_time | DATETIME2 | NULL | 更新时间 |

**树形结构示例**：
```
I (文学)
├─ I2 (中国文学)
│  ├─ I24 (小说)
│  │  ├─ I247 (现代作品)
│  │  │  ├─ I247.5 (新体长篇、中篇小说)
│  │  │  └─ I247.7 (新体短篇小说)
│  │  └─ I242 (古代作品)
```

### 2.4 库位表 (STORAGE_LOCATION)

**用途**：描述图书存放位置及库存管理

### 2.8 馆藏实体表 (BOOK_ITEM)

**用途**：条码级馆藏记录，每一本实体书一条记录

| 字段名 | 数据类型 | 约束 | 说明 |
|--------|---------|------|------|

**当前状态**：
- AVAILABLE：可借

**物理状态**：
- GOOD：完好

**索引**：
```sql
CREATE INDEX IX_book_item_status ON BOOK_ITEM(current_status)
```

### 2.11 图书预约表 (book_reservation)

**用途**：读者预约图书的记录

| 字段名 | 数据类型 | 约束 | 说明 |
|--------|---------|------|------|
| reservation_id | BIGINT | PK | 预约编号 |
| cardID | NVARCHAR(20) | FK | 借书证号 |
| bookID | NVARCHAR(30) | FK | 馆藏条码 |
| reservation_type | NVARCHAR(20) | NOT NULL | 预约类型 |
| reservation_time | DATETIME2 | DEFAULT | 预约时间 |
| expire_time | DATETIME2 | NOT NULL | 过期时间 |
| pickup_time | DATETIME2 | NULL | 实际取书时间 |
| reservation_status | NVARCHAR(20) | NOT NULL | 预约状态 |
| note | NVARCHAR(200) | NULL | 备注 |

**预约类型**：
- BORROW_RESERVE：借阅预约（已借出，等待归还）
- NEW_BOOK：新书预约（新书待到货）

**预约状态**：
- PENDING：待处理
- FULFILLED：已完成
- EXPIRED：已过期
- CANCELLED：已取消

**唯一约束**：
```sql
-- 同一读者对同一本书只能有一条待处理预约
CREATE UNIQUE INDEX UX_book_reservation_active 
ON book_reservation(cardID, bookID) 
WHERE reservation_status = 'PENDING';
```

### 2.18 罚款规则表 (FINE_RULES)

**用途**：存储不同读者类型的罚款规则配置

| 字段名 | 数据类型 | 约束 | 说明 |
|--------|---------|------|------|
| rule_id | INT | PK | 规则编号 |
| reader_type | NVARCHAR(20) | UNIQUE | 读者类型 |
| overdue_price_rate | DECIMAL(5,4) | NOT NULL | 逾期书价百分比 |
| overdue_day_rate | DECIMAL(5,2) | NOT NULL | 逾期每天罚款 |
| lost_rate | DECIMAL(5,4) | NOT NULL | 丢失赔偿系数 |
| damaged_rate | DECIMAL(5,4) | NOT NULL | 严重破损系数 |
| minor_damaged_rate | DECIMAL(5,4) | NOT NULL | 轻微破损系数 |
| max_overdue_fine | DECIMAL(10,2) | NULL | 最大逾期罚款 |
| max_total_fine | DECIMAL(10,2) | NULL | 最大总罚款 |
| free_overdue_days | INT | NOT NULL | 免罚天数 |
| is_active | BIT | DEFAULT | 是否启用 |
| created_time | DATETIME | DEFAULT | 创建时间 |
| updated_time | DATETIME | NULL | 更新时间 |
| remark | NVARCHAR(500) | NULL | 备注说明 |

**罚款计算公式**：
```
逾期罚款 = 书价 × overdue_price_rate + 逾期天数 × overdue_day_rate
丢失赔偿 = 书价 × lost_rate
破损赔偿 = 书价 × damaged_rate
轻微破损 = 书价 × minor_damaged_rate
```

## 4. 关键存储过程

### 4.1 生成借书证号

```sql
EXEC sp_generate_card_id
    @readerType = N'本校学生',
    @cardID = @newCardID OUTPUT
```

**功能**：自动生成格式为 `BRW-YYYY-T-NNNNNN` 的借书证号

---

### 4.2 计算罚款金额

```sql
EXEC sp_calculate_fine
    @bookID = 'BK-000001',
    @fineType = 'OVERDUE',
    @overdueDays = 5,
    @fineAmount = @amount OUTPUT
```

**功能**：根据图书信息和罚款类型计算罚款金额

---

### 4.3 校验续借资格

```sql
EXEC sp_ValidateRenewEligibility
    @bookID = 'BK-000001',
    @result = @isEligible OUTPUT
```

**功能**：校验图书是否满足续借条件

---

### 4.4 获取借阅规则

```sql
EXEC sp_GetBorrowRuleByReaderType
    @reader_type = N'本校学生'
```

**功能**：获取特定读者类型的借阅规则

## 6. 数据一致性保证

### 6.1 外键约束

```sql
-- reader -> readcard
ALTER TABLE dbo.reader
ADD CONSTRAINT FK_reader_readcard
FOREIGN KEY(cardID) REFERENCES dbo.readcard(cardID);

-- borrow_record -> reader
ALTER TABLE dbo.borrow_record
ADD CONSTRAINT FK_borrow_record_reader
FOREIGN KEY(cardID) REFERENCES dbo.reader(cardID);

-- bookborrow -> reader/BOOK_ITEM/borrow_record
ALTER TABLE dbo.bookborrow
ADD CONSTRAINT FK_bookborrow_reader
FOREIGN KEY(cardID) REFERENCES dbo.reader(cardID);

-- book_reservation -> reader/BOOK_ITEM
ALTER TABLE dbo.book_reservation
ADD CONSTRAINT FK_book_reservation_reader
FOREIGN KEY(cardID) REFERENCES dbo.reader(cardID);

-- fine -> reader
ALTER TABLE dbo.fine
ADD CONSTRAINT FK_fine_reader
FOREIGN KEY(cardID) REFERENCES dbo.reader(cardID);
```

### 6.2 检查约束

```sql
-- 借书证格式
CONSTRAINT CK_readcard_format CHECK (
    cardID LIKE 'BRW-[0-9][0-9][0-9][0-9]-[1-3]-[0-9][0-9][0-9][0-9][0-9][0-9]'
)

-- 到期日期一致性
CONSTRAINT CK_readcard_overdate_1y CHECK 
(overdate = DATEADD(YEAR, 1, startdate))

-- 年份一致性
CONSTRAINT CK_readcard_year_match CHECK 
(SUBSTRING(cardID, 5, 4) = CONVERT(CHAR(4), YEAR(startdate)))

-- 读者类型约束
CONSTRAINT CK_reader_number_rule CHECK (
    (readertype IN ('本校学生','本校教师') AND [number] IS NOT NULL)
    OR
    (readertype = '校外人员' AND [number] IS NULL)
)

-- 借阅时间一致性
CONSTRAINT CK_bookborrow_time CHECK 
(overdate IS NULL OR overdate >= borrowdate)
```
