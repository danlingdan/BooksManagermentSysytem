## 🔍 关键概念速查

### 读者分类
- **本校学生**：代码1，借期7天，最多3本
- **本校教师**：代码2，借期30天，最多5本
- **校外人员**：代码3，借期7天，最多2本

### 借书证号格式
```
BRW-YYYY-T-NNNNNN
BRW：固定前缀
YYYY：年份
T：类别码（1=学生，2=教师，3=校外）
NNNNNN：6位序号
```

### 权限分类
- **BOOK_CATALOG**：图书编目
- **BORROW_OPERATION**：借阅操作
- **BORROW_RENEW**：续借操作
- **RESERVATION_MANAGE**：预约管理
- **FINE_MANAGE**：罚款管理
- **USER_MANAGE**：用户管理

### 重要日期
- **借书证有效期**：1年
- **预约有效期**：3天
- **逾期提醒**：到期前1天
- **证件续期提醒**：到期前30天
