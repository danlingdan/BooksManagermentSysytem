## 1. 续借功能

### 1.1 续借概述

**定义**：读者在图书未逾期的情况下，申请延长还书期限

**条件**：
- 图书已借出且未逾期
- 未达到最大续借次数
- 该图书未被他人预约
- 读者无未支付罚款

### 1.2 续借资格校验

```
校验续借条件
    ├─ 检查图书是否已借出
    ├─ 检查是否已逾期
    ├─ 检查续借次数是否达上限
    ├─ 检查是否有预约冲突
    ├─ 检查读者是否有罚款
    └─ 检查借书证是否有效
    ↓
条件满足 → 允许续借
条件不满足 → 拒绝续借，给出原因
```

### 1.3 续借执行

```
计算新的到期日期
    └─ 新到期日 = 当前日期 + 续借天数
    ↓
更新borrowdate记录
    ├─ renew_count + 1
    ├─ last_renew_time = 当前时间
    └─ 保存新的应还日期（bookborrow.overdate）
    ↓
记录续借日志
    ├─ 操作人
    ├─ 续借时间
    └─ 新的应还日期
    ↓
续借完成，返回新的到期日期
```

### 1.4 续借规则表

| 读者类型 | 最大续借次数 | 每次续借天数 |
|---------|------------|-----------|
| 本校学生 | 2次 | 15天 |
| 本校教师 | 3次 | 30天 |
| 校外人员 | 1次 | 7天 |

### 1.5 续借存储过程

```sql

    @bookID = 'BK-000001',
    @isEligible = @result OUTPUT

EXEC sp_ProcessRenew
    @bookID = 'BK-000001',
    @cardID = 'BRW-2025-1-000001',
    @success = @result OUTPUT
```

## 3. 图书预约功能

### 3.1 预约概述

**定义**：读者预约已借出或新书的图书，在满足条件时自动通知取书

**预约类型**：
1. **借阅预约**：图书已借出，等待归还取书
2. **新书预约**：新书待到货，预约后优先取书

### 3.2 预约生命周期

```
创建预约 → 待处理 → 已完成/已过期/已取消
    │
    ├─ PENDING (待处理)
    │   ├─ 图书归还后 → FULFILLED (已完成)
    │   ├─ 3天未取书 → EXPIRED (已过期)
    │   └─ 读者取消 → CANCELLED (已取消)
    │
    ├─ FULFILLED (已完成)
    │   └─ 最终状态
    │
    ├─ EXPIRED (已过期)
    │   └─ 最终状态
    │
    └─ CANCELLED (已取消)
        └─ 最终状态
```

### 3.3 预约限制

| 限制项 | 限制值 | 说明 |
|--------|--------|------|
| 最大预约数 | 3本 | 单个读者最多预约3本图书 |
| 最大预约分类 | 2个 | 最多预约2个不同分类的图书 |
| 预约有效期 | 3天 | 3天内未取书自动取消 |
| 重复预约 | 禁止 | 同一图书只能预约一次 |

### 3.4 预约检查

```sql
-- 同一读者对同一本书只能有一条待处理预约
CREATE UNIQUE INDEX UX_book_reservation_active 
ON book_reservation(cardID, bookID) 
WHERE reservation_status = 'PENDING'
```

## 5. 预约与借阅的关系

### 5.1 图书归还时的预约检查

```
图书归还
    ↓
检查是否有待处理预约
    ├─ 查询book_reservation WHERE bookID=@bookID AND status=PENDING
    └─ 按预约时间排序
    ↓
若有预约
    ├─ 更新图书状态为RESERVED
    ├─ 转移到预约书架库位
    ├─ 更新预约记录
    ├─ 发送通知（短信/邮件）
    └─ 计算取书截止时间（3天）
    ↓
若无预约
    ├─ 正常上架
    └─ 状态为AVAILABLE
```

### 5.2 预约书籍的取书

```
读者取书
    ↓
查询待取预约
    ├─ reservation_status = PENDING
    ├─ expire_time > 当前日期
    └─ 显示取书清单
    ↓
读者确认取书
    ├─ 扫描条码
    ├─ 核实图书信息
    ├─ 更新预约状态为FULFILLED
    ├─ 图书状态变为BORROWED
    └─ 更新reservation_time
    ↓
取书成功
```

### 5.3 预约过期自动处理

```
后台定时任务（每天运行）
    ↓
查询过期预约
    └─ WHERE expire_time < 当前日期 AND status = PENDING
    ↓
对每条过期预约
    ├─ 更新状态为EXPIRED
    ├─ 图书恢复AVAILABLE状态
    ├─ 转移回原库位
    └─ 记录过期日志
    ↓
任务完成
```

## 6. 预约相关视图与存储过程

### 6.1 视图：待处理预约

```sql
CREATE VIEW vw_pending_reservations AS
SELECT 
    r.reservation_id,
    r.cardID,
    rd.readername,
    bi.item_barcode,
    bib.bibliography_name,
    r.reservation_time,
    r.expire_time,
    DATEDIFF(DAY, GETDATE(), r.expire_time) AS 剩余天数
FROM book_reservation r
INNER JOIN reader rd ON r.cardID = rd.cardID
INNER JOIN BOOK_ITEM bi ON r.bookID = bi.item_barcode
INNER JOIN BIBLIOGRAPHY bib ON bi.bibliography_id = bib.bibliography_id
WHERE r.reservation_status = 'PENDING'
ORDER BY r.reservation_time ASC
```

### 6.2 存储过程：处理过期预约

```sql
CREATE PROCEDURE sp_ExpireReservations
AS
BEGIN
    -- 更新过期预约
    UPDATE book_reservation
    SET reservation_status = 'EXPIRED'
    WHERE reservation_status = 'PENDING'
        AND expire_time < GETDATE()
    
    -- 恢复图书状态
    UPDATE bi
    SET bi.current_status = 'AVAILABLE'
    FROM BOOK_ITEM bi
    INNER JOIN book_reservation br ON bi.item_barcode = br.bookID
    WHERE br.reservation_status = 'EXPIRED'
END
```

## 7. 通知机制

### 7.1 通知类型

| 事件 | 通知类型 | 内容 |
|------|---------|------|
| 预约书到货 | 短信/邮件 | 书籍已到，请于3天内取书 |
| 预约即将过期 | 提醒 | 预约即将过期，请及时取书 |
| 续借成功 | 提醒 | 续借成功，新应还日期为... |
| 续借失败 | 提醒 | 续借失败原因，请处理后重试 |

### 7.2 通知实现

```csharp
public void SendReservationNotification(string cardID, string bookName)
{
    var reader = GetReader(cardID);
    
    if (!string.IsNullOrEmpty(reader.Email))
    {
        SendEmail(reader.Email, 
            $"预约图书已可取", 
            $"您预约的《{bookName}》已可取书，请于3天内到图书馆取书");
    }
    
    if (!string.IsNullOrEmpty(reader.Phone))
    {
        SendSMS(reader.Phone, 
            $"预约图书已可取，请于3天内来馆取书");
    }
}
```

## 8. 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 无法续借 | 已达续借次数 | 归还后重新借阅 |
| 无法续借 | 图书有人预约 | 提前归还 |
| 无法预约 | 已预约同一图书 | 取消原预约后重新预约 |
| 无法预约 | 预约数达限制 | 取消其他预约 |
| 预约过期 | 超过3天未取 | 重新预约 |

## 9. 最佳实践

### 9.1 续借建议

1. **及时续借**
   - 在逾期前续借
   - 预留续借机会

2. **检查预约冲突**
   - 他人已预约，无法续借
   - 归还后可重新借阅

### 9.2 预约建议

1. **合理预约**
   - 按需预约，避免浪费
   - 及时取书，不要过期

2. **取消机制**
   - 用不到的预约及时取消
   - 为其他读者让出机会

### 9.3 运维建议

1. **定期检查**
   - 每日运行过期预约处理
   - 监控预约队列长度

2. **问题处理**
   - 异常预约手工介入
   - 特殊情况人工审批
