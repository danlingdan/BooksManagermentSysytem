## 1. 借阅业务流程

### 1.1 借阅资格校验

```
输入借书证号
    ↓
查询读者信息
    ↓
检查借书证是否有效
    ├─ 证件状态：必须为"正常"
    ├─ 证件有效期：不能已过期
    └─ 读者激活状态：必须启用
    ↓
检查读者是否有逾期书籍
    └─ 若有逾期，禁止借阅
    ↓
检查读者是否有未支付罚款
    └─ 若有，提醒支付但不禁止
    ↓
读者资格有效
```

### 1.2 借阅数量与分类限制

```
检查当前借阅数量
    ├─ 已借数量 + 新借数量 ≤ 最大借数
    └─ 超限则拒绝
    ↓
检查借阅分类数
    ├─ 已借分类 + 新分类 ≤ 最大分类数
    └─ 超限则拒绝
    ↓
检查是否可借特定类型图书
    ├─ 工具书：仅馆内浏览，不外借
    └─ 新书：根据规则判断
```

### 1.3 图书状态校验

```
检查图书状态
    ├─ AVAILABLE：可借
    ├─ BORROWED：已借出，不可借
    ├─ OFF_SHELF：下架维修，不可借
    └─ RESERVED：被预约，可借但需要提醒
    ↓
检查图书库位
    └─ 必须在流通区，不能在待修复等特殊区
```

### 1.4 借阅执行

```
创建借阅单头(borrow_record)
    ├─ cardID：借书证号
    ├─ borrowdate：借阅时间（当前时间）
    ├─ overdate：NULL（未还）
    └─ bcomplete：完好（默认）
    ↓
创建借阅明细(bookborrow)
    ├─ 对应borrow_record_id
    ├─ 对应bookID（图书条码）
    ├─ borrowdate：借出时间
    └─ overdate：NULL（未还）
    ↓
更新图书状态
    ├─ BOOK_ITEM.current_status = BORROWED
    └─ 更新库位库存数量
    ↓
借阅成功，显示
    ├─ 应还日期（借阅日期 + 借期）
    ├─ 续借次数（初始为0）
    └─ 其他提示信息
```

### 1.5 应还日期计算

```
应还日期 = 借阅日期 + 借期天数

示例：
- 本校学生：借期7天
  借书：2025-01-05 → 应还：2025-01-12
- 本校教师：借期30天
  借书：2025-01-05 → 应还：2025-02-04
```

## 2. 归还业务流程

### 2.1 查询未还书籍

```
输入借书证号
    ↓
查询该读者所有未还书籍
    ├─ 从bookborrow表查询 overdate IS NULL
    ├─ 关联BOOK_ITEM获取书名
    └─ 关联BIBLIOGRAPHY获取图书信息
    ↓
显示未还书籍列表
    ├─ 借出日期
    ├─ 应还日期
    ├─ 已逾期天数（若逾期）
    └─ 书籍名称等信息
```

### 2.2 逾期检查

```
检查是否逾期
    ├─ 当前日期 > 应还日期？
    ├─ 是 → 计算逾期天数
    └─ 否 → 正常归还
    ↓
若逾期，在界面高亮提示
    └─ 红色背景标记逾期记录
```

### 2.3 罚款计算

```
根据归还状态计算罚款：

1. 完好归还
   ├─ 若逾期：罚款 = 书价×0.1 + 逾期天数×0.1
   └─ 若按期：无罚款

2. 轻微破损
   ├─ 赔偿 = 书价 × 0.25
   └─ 如果同时逾期，取较大者

3. 严重破损
   ├─ 赔偿 = 书价 × 0.5
   └─ 如果同时逾期，取较大者

4. 丢失
   └─ 赔偿 = 书价 × 1.0（全额赔偿）
```

### 2.4 归还执行

```
选择要归还的书籍
    ↓
选择归还状态（完好/轻微破损/严重破损/丢失）
    ↓
输入补充说明（如有破损）
    ↓
系统自动计算罚款金额
    ↓
显示罚款预览
    ├─ 罚款原因
    ├─ 罚款金额
    └─ 确认
    ↓
点击"确认归还"
    ↓
执行数据库操作
    ├─ 更新bookborrow.overdate = 当前时间
    ├─ 更新borrow_record.bcomplete = 归还状态
    ├─ 更新BOOK_ITEM.current_status
    ├─ 创建fine记录（若有罚款）
    └─ 更新库位库存
    ↓
归还成功
    ├─ 显示应收罚款
    └─ 提醒预约情况
```

### 2.5 状态更新规则

| 归还状态 | BOOK_ITEM状态 | physical_condition | 说明 |
|---------|-------------|-------------------|------|
| 完好 | AVAILABLE | GOOD | 直接上架 |
| 轻微破损 | OFF_SHELF | DAMAGED | 转待修复 |
| 严重破损 | OFF_SHELF | DAMAGED | 转待修复 |
| 丢失 | OFF_SHELF | REPAIR | 下架记录 |

## 5. 预约检查与处理

### 5.1 归还时的预约检查

```
图书归还
    ↓
检查是否有预约
    ├─ 查询book_reservation表
    ├─ 过滤PENDING状态的预约
    └─ 按预约时间排序
    ↓
若有预约
    ├─ 更新图书状态为RESERVED
    ├─ 转移到预约书架
    ├─ 通知读者取书
    └─ 发送短信/邮件
```

### 5.2 预约队列管理

```sql
-- 查询待处理预约
SELECT TOP 1 
    reservation_id,
    cardID,
    reservation_time,
    DATEADD(DAY, 3, reservation_time) AS expire_time
FROM book_reservation
WHERE bookID = @bookID 
    AND reservation_status = 'PENDING'
ORDER BY reservation_time ASC
```

## 6. 借阅规则配置

### 6.1 可配置规则

```sql
SELECT 
    reader_type,
    max_borrow_count,      -- 最大借数
    borrow_days,           -- 借期（天）
    max_renew_count,       -- 最大续借次数
    renew_days,            -- 续借天数
    allow_reference_books  -- 是否可借工具书
FROM BORROW_RULES
WHERE is_active = 1
```

### 6.2 规则查询

```csharp
public BorrowRules GetBorrowRule(string readerType)
{
    using (SqlCommand cmd = new SqlCommand("sp_GetBorrowRuleByReaderType", conn))
    {
        cmd.CommandType = CommandType.StoredProcedure;
        cmd.Parameters.AddWithValue("@reader_type", readerType);
        
        using (SqlDataReader reader = cmd.ExecuteReader())
        {
            if (reader.Read())
            {
                return new BorrowRules
                {
                    MaxBorrowCount = (int)reader["max_borrow_count"],
                    BorrowDays = (int)reader["borrow_days"],
                    MaxRenewCount = (int)reader["max_renew_count"]
                };
            }
        }
    }
    
    return null;
}
```

## 7. 常见问题处理

| 问题 | 症状 | 解决方案 |
|------|------|---------|
| 证件无效 | 无法查询借书证 | 检查证件状态是否为"正常" |
| 借数超限 | 提示已达最大借数 | 先还书或申请增加借数 |
| 逾期无法借 | 禁止借书 | 归还逾期图书或支付罚款 |
| 特殊类型书不可借 | 工具书无法借出 | 仅限馆内查阅 |
| 图书已预约 | 借出时给出提醒 | 可借但提醒有预约 |
