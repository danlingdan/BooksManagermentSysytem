## 1. 认证系统总体设计

### 1.1 认证流程

```
用户输入凭据
    ↓
密码验证
    ↓
权限加载
    ↓
登录成功/失败
    ↓
生成会话
```

### 1.2 认证方式

系统支持两种认证方式：

1. **应用认证**：使用app_user表中的用户名/密码
2. **Windows认证**：支持Windows域账户登录

### 1.3 密码安全机制

- **加盐哈希**：使用SHA2_256 + salt
- **盐值生成**：每个用户独立生成64位盐值
- **密码强度**：不对密码强度做前端限制，交由业务规则定义

## 2. 登录系统详解

### 2.1 LoginForm 登录窗体

**功能**：提供用户登录界面

**界面组件**：
- 用户名输入框
- 密码输入框
- 记住密码复选框
- 登录/取消按钮

**验证流程**：

```csharp
1. 验证输入不为空
2. 调用 AuthenticationService.Login()
3. 数据库查询用户
4. 对比密码哈希
5. 加载用户权限
6. 更新最后登录时间
7. 返回登录结果
```

### 2.2 注册系统 (RegisterForm)

**功能**：新用户自助注册

**支持的用户类型**：
- Reader（读者）
- Librarian（图书管理员）- 需要邀请码
- Admin（系统管理员）- 系统预设

**注册流程**：

```
输入注册信息
    ↓
验证邀请码（仅限管理员）
    ↓
检查用户名是否存在
    ↓
验证密码一致性
    ↓
生成盐值并计算密码哈希
    ↓
插入app_user表
    ↓
创建读者记录（如果是读者）
    ↓
注册完成
```

### 2.3 密码修改 (ChangePasswordForm)

**功能**：登录后用户修改密码

**验证项**：
- 旧密码验证
- 新密码与确认密码一致
- 新密码不能与旧密码相同

### 3.1 权限模型

系统采用 **RBAC（基于角色的访问控制）** 模型：

```
User (用户)
    ↓
Role (角色)
    ↓
Permission (权限)
    ↓
Resource (资源/功能)
```

#### 5.3.3 数据库级权限检查

```sql
-- 存储过程中的权限检查
CREATE PROCEDURE sp_check_user_permission
    @user_id INT,
    @permission_code NVARCHAR(50)
AS
BEGIN
    SELECT COUNT(*) AS has_permission
    FROM sys_role_permission rp
    INNER JOIN app_user u ON u.user_role = rp.role_name
    WHERE u.user_id = @user_id 
        AND rp.permission_code = @permission_code
        AND u.is_active = 1
END
```

## 7. 密码管理

### 7.1 密码存储

**存储方式**：
```sql
INSERT INTO app_user(username, password_hash, salt, user_role, display_name)
VALUES(
    @username,
    HASHBYTES('SHA2_256', @password + @salt),
    @salt,
    @user_role,
    @display_name
)
```

### 7.2 密码验证

**验证逻辑**：

```csharp
public bool VerifyPassword(string username, string password)
{
    // 1. 查询用户的盐值
    var salt = GetUserSalt(username);
    
    // 2. 计算输入密码的哈希
    var inputHash = ComputeHash(password + salt);
    
    // 3. 与数据库哈希比对
    var dbHash = GetUserPasswordHash(username);
    
    return inputHash == dbHash;
}
```

### 7.3 密码修改流程

```
输入旧密码
    ↓
验证旧密码正确性
    ↓
输入新密码（两次）
    ↓
验证新密码强度（可选）
    ↓
验证新密码与确认密码一致
    ↓
生成新盐值
    ↓
计算新密码哈希
    ↓
更新数据库
    ↓
修改成功
```

## 10. 实现示例

### 10.1 登录实现

```csharp
private void LoginForm_Load(object sender, EventArgs e)
{
    // 初始化UI
}

private void ButtonLogin_Click(object sender, EventArgs e)
{
    string username = textBoxUsername.Text.Trim();
    string password = textBoxPassword.Text;
    
    if (string.IsNullOrEmpty(username) || string.IsNullOrEmpty(password))
    {
        MessageBox.Show("用户名和密码不能为空");
        return;
    }
    
    try
    {
        if (AuthenticationService.Instance.Login(username, password))
        {
            MessageBox.Show("登录成功");
            
            // 打开主窗体
            MainForm mainForm = new MainForm();
            mainForm.Show();
            
            // 关闭登录窗体
            this.Hide();
        }
        else
        {
            MessageBox.Show("用户名或密码错误");
            textBoxPassword.Clear();
            textBoxPassword.Focus();
        }
    }
    catch (Exception ex)
    {
        MessageBox.Show($"登录失败：{ex.Message}");
    }
}
```

```csharp
private void ButtonRegister_Click(object sender, EventArgs e)
{
    string username = textBoxUsername.Text.Trim();
    string password = textBoxPassword.Text;
    string confirmPassword = textBoxConfirmPassword.Text;
    string userRole = comboBoxRole.SelectedValue?.ToString() ?? "Reader";
    
    // 验证
    if (string.IsNullOrEmpty(username))
    {
        MessageBox.Show("用户名不能为空");
        return;
    }
    
    if (password != confirmPassword)
    {
        MessageBox.Show("密码不一致");
        return;
    }
    
    if (password.Length < 6)
    {
        MessageBox.Show("密码长度至少6个字符");
        return;
    }
    
    try
    {
        // 调用注册服务
        if (RegisterUser(username, password, userRole))
        {
            MessageBox.Show("注册成功，请使用新账户登录");
            this.Close();
        }
    }
    catch (Exception ex)
    {
        MessageBox.Show($"注册失败：{ex.Message}");
    }
}
```
