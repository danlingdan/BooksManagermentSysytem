## 1. 图书分类管理

### 1.1 分类体系

采用**中图法（中国图书馆分类法）**的树形结构

```
A 马克思主义、列宁主义、毛泽东思想
B 哲学、宗教
C 社会科学总论
D 政治学、法律
E/F 历史、地理
G 文化、科学、教育、体育
H 语言、文字
I 文学
J 艺术
K 历史、地理
N 自然科学总论
O 数学、物理、化学
P 天文学、地球科学
Q 生物科学
R 医药、卫生
S 农业
T 工业技术
U 交通运输
V 航空、航天
X 环境科学、安全科学
Z 综合性图书
```

### 1.2 分类树结构示例

```
I (文学)
├─ I0 (中国文学理论)
├─ I2 (中国文学)
│  ├─ I24 (小说)
│  │  ├─ I242 (古代作品)
│  │  └─ I247 (现代作品)
│  │     ├─ I247.5 (新体长篇、中篇小说)
│  │     └─ I247.7 (新体短篇小说)
│  ├─ I25 (诗歌)
│  └─ I26 (戏剧)
├─ I3 (古代外国文学)
└─ I5 (现代外国文学)
```

#### 1.3.2 修改分类

- 可修改：名称、描述
- 不可修改：分类代码、父分类

#### 1.3.3 删除分类

**删除条件**：
- 该分类下无书目
- 该分类无子分类

#### 1.3.4 查询分类

```sql
-- 树形查询
WITH CategoryTree AS (
    SELECT category_id, category_code, category_name, parent_category_id, 0 AS level
    FROM BOOK_CATEGORY
    WHERE parent_category_id IS NULL
    
    UNION ALL
    
    SELECT bc.category_id, bc.category_code, bc.category_name, bc.parent_category_id, ct.level + 1
    FROM BOOK_CATEGORY bc
    INNER JOIN CategoryTree ct ON bc.parent_category_id = ct.category_id
)
SELECT * FROM CategoryTree ORDER BY level, category_code
```

### 2.3 ISBN管理

**ISBN格式校验**：
- ISBN-10：10位数字
- ISBN-13：13位数字（推荐）

```csharp
public bool IsValidISBN(string isbn)
{
    if (string.IsNullOrEmpty(isbn))
        return false;
    
    isbn = isbn.Replace("-", "").Replace(" ", "");
    
    // 验证ISBN-10
    if (isbn.Length == 10)
    {
        return ValidateISBN10(isbn);
    }
    
    // 验证ISBN-13
    if (isbn.Length == 13)
    {
        return ValidateISBN13(isbn);
    }
    
    return false;
}
```

## 3. 馆藏管理

### 3.1 馆藏实体信息

```csharp
public class BookItem
{
    public string ItemBarcode { get; set; }          // 条码
    public int BibliographyId { get; set; }          // 书目ID
    public string CurrentStatus { get; set; }        // 状态
    public int LocationId { get; set; }              // 库位ID
    public DateTime AcquisitionDate { get; set; }    // 入库日期
    public decimal? Price { get; set; }              // 购置价格
    public string PhysicalCondition { get; set; }    // 物理状态
    public DateTime StatusChangedDate { get; set; }  // 状态变更时间
}
```

### 3.2 馆藏状态机

```
AVAILABLE (可借)
    ↓
BORROWED (已借出)
    ↓
AVAILABLE (回库)
    ↓
OFF_SHELF (下架)
或
RESERVED (预约中)
```

**状态详解**：

| 状态 | 代码 | 说明 | 是否可借 |
|------|------|------|---------|
| 可借 | AVAILABLE | 在架可借 | ✅ |
| 已借 | BORROWED | 已借出未归 | ❌ |
| 下架 | OFF_SHELF | 维修/整理中 | ❌ |
| 预约 | RESERVED | 被预约待取 | ❌ |

### 3.3 新增馆藏

```
选择书目
    ↓
输入馆藏条码（自动生成或手工输入）
    ↓
输入购置价格
    ↓
选择库位
    ↓
输入入库日期
    ↓
保存馆藏记录
    ↓
更新库位数量
    ↓
记录编目日志
```

### 3.4 条码管理

**条码生成策略**：

1. **自动生成**：系统自动分配
   ```
   BK-NNNNNN（BK代表图书，后接6位序号）
   ```

2. **手工输入**：使用实际的图书馆条码
   ```
   支持任何格式的条码编号
   ```

3. **条码唯一性**
   ```sql
   CREATE UNIQUE INDEX UX_book_item_barcode 
   ON BOOK_ITEM(item_barcode)
   ```

### 3.5 物理状态管理

| 状态 | 代码 | 说明 | 处理方式 |
|------|------|------|---------|
| 完好 | GOOD | 无损伤 | 正常流通 |
| 破损 | DAMAGED | 有破损 | 转待修复区 |
| 维修 | REPAIR | 维修中 | 等待修复完成 |

**损坏上报流程**：

```
归还时发现破损
    ↓
选择破损程度
    ↓
输入破损描述
    ↓
系统标记为破损
    ↓
转移到待修复库位
    ↓
记录修复记录
    ↓
修复完成后恢复可借状态
```

## 4. 库位管理

### 4.1 库位体系

采用树形结构表示物理库位

```
一楼
├─ A区
│  ├─ 01排
│  │  ├─ 01架
│  │  │  ├─ 1层
│  │  │  ├─ 2层
│  │  │  └─ 3层
│  │  └─ 02架
│  └─ 02排
└─ B区

热门区
├─ 01号架
└─ 02号架

新书区
├─ 01号架
└─ 02号架

工具书区
└─ 01号架

期刊区
└─ 01号架

预约书架
└─ 01号架

待修复区
└─ 01号架
```

### 4.2 库位类型

| 类型 | 代码 | 说明 | 特殊规则 |
|------|------|------|---------|
| 常规书架 | REGULAR_SHELF | 主要流通架 | 无 |
| 热门区 | HOT_ZONE | 借阅热门图书 | 流通频繁 |
| 新书区 | NEW_BOOK | 新入库图书 | 3个月后自动转出 |
| 工具书区 | REFERENCE | 工具书 | 仅馆内浏览，不外借 |
| 期刊区 | JOURNAL | 期刊杂志 | 按期管理 |
| 预约书架 | RESERVATION_SHELF | 待取书架 | 用于预约书籍暂放 |
| 待修复区 | REPAIR_AREA | 破损图书 | 等待修复 |

### 4.3 库位状态

| 状态 | 代码 | 说明 |
|------|------|------|
| 正常 | ACTIVE | 正常使用 |
| 停用 | INACTIVE | 暂不使用 |
| 维修中 | MAINTENANCE | 库位维修中 |
| 已满 | FULL | 库存已满 |
| 整理中 | ORGANIZING | 整理中 |

### 4.4 库位容量管理

```csharp
public bool CanAddBookToLocation(int locationId, int bookCount)
{
    var location = GetLocation(locationId);
    
    // 检查是否有容量
    if (location.CurrentQuantity + bookCount > location.MaxCapacity)
    {
        throw new InvalidOperationException("库位容量不足");
    }
    
    // 检查库位状态
    if (location.Status != "ACTIVE")
    {
        throw new InvalidOperationException("库位不可用");
    }
    
    return true;
}
```

#### 4.5.2 库存统计

```sql
-- 按库位统计
SELECT 
    location_code,
    location_name,
    location_type,
    max_capacity,
    current_quantity,
    max_capacity - current_quantity AS 可用容量,
    CAST(current_quantity * 100.0 / max_capacity AS DECIMAL(5,2)) AS 占用率
FROM STORAGE_LOCATION
ORDER BY 占用率 DESC
```

## 9. 编目日志与审计

所有编目操作自动记录在`catalog_log`表：

| 操作类型 | 目标类型 | 记录信息 |
|---------|---------|---------|
| 新增 | BIBLIOGRAPHY | 新书ISBN、书名等 |

| 删除 | BOOK_ITEM | 删除条码、原库位 |
| 上架 | BOOK_ITEM | 条码、库位 |
| 下架 | BOOK_ITEM | 条码、下架原因 |

### 9.2 查询日志

```sql
-- 查询最近的编目操作
SELECT TOP 50 * FROM catalog_log
ORDER BY action_time DESC

-- 查询特定用户的操作
SELECT * FROM catalog_log
WHERE operator = @operator
ORDER BY action_time DESC
```

### 10.2 库存维护建议

1. **定期盘点**
   ```sql
   -- 库存盘点查询
   SELECT location_id, location_name, max_capacity, current_quantity,
          max_capacity - current_quantity AS 可用容量
   FROM STORAGE_LOCATION
   WHERE status = 'ACTIVE'
   ORDER BY CAST(current_quantity AS FLOAT) / max_capacity DESC
   ```
