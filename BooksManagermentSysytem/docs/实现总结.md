## 使用说明

### 续借流程
1. 打开续借管理界面
2. 输入借书证号查询读者信息
3. 系统自动加载可续借书籍列表
4. 选择要续借的书籍
5. 查看续借信息（已续借次数、当前到期日、续借后到期日）
6. 点击"办理续借"按钮
7. 系统自动校验并完成续借

### 预约流程
1. 打开预约管理界面
2. 输入借书证号查询读者信息
3. 在"新建预约"标签页搜索图书
4. 从搜索结果中添加要预约的书籍
5. 确认预约列表
6. 点击"确认预约"按钮
7. 系统创建预约并显示取书截止时间

### 查看和取消预约
1. 切换到"我的预约"标签页
2. 查看所有预约记录（包括待处理、已完成、已过期、已取消）
3. 选择要取消的预约（仅"待处理"状态可取消）
4. 点击"取消预约"按钮
5. 确认后系统更新预约状态

## 注意事项

1. **数据库兼容性**：脚本使用 SQL Server 2016+ 特性，确保数据库版本兼容
2. **规则配置**：首次部署后，请根据实际需求调整 `borrow_rule` 和 `fine_rule` 表中的规则
3. **定时任务**：建议配置定时任务定期调用 `sp_ExpireReservations` 处理过期预约
4. **性能监控**：注意监控新增索引的性能影响
5. **用户权限**：确保图书管理员有续借管理权限，读者有预约权限
